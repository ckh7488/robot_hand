# 생성기 입력과 보존 기준

## 현재 main: 원위 모터 재배치

새 설계 입력은 `cad/remote_drive_v1/design.json`, 형상 생성기는 같은 폴더의 `generate.py`입니다. 입력 치수는 V9의 손바닥·뿌리 위치·링크 길이에서 출발하지만 새 후보와 기존 기준을 구분해 관리합니다. 실제 CAD에서 집계한 `simulation_contract.json`을 `sim/remote_drive_v1`의 동역학 모델에 전달합니다. 질량·관성의 좌표계, 움직이는 모터의 소속 강체, 출력축과 줄 전달비가 서로 일치해야 합니다.

새 시뮬레이션의 제어기·전류·마찰·탄성은 실측 전 가정입니다. 새 CAD 입력이나 전달 구조가 바뀌면 해당 계약과 동역학 결과도 다시 만들어야 합니다. 모델이 아직 지원하지 않는 전달 경로나 충돌은 결과의 제외 범위로 남기며, 시각적 형상이 있다는 이유만으로 동역학에 반영됐다고 쓰지 않습니다.

## 보존된 V9~V13의 호환 입력

V9 build_candidate.py는 원본 sources/XL330.stp, cad/index_joint_v1의 ROBOTIS 프레임 STEP, 루트 robot_config.json을 읽습니다. 모두 원본 바이트로 보존했습니다.

robot_config.json의 작은 손 치수/구동 가정은 역사적인 입력입니다. 현재 CAD 생성기가 사용하는 것은 arm.motors의 모터 외형과 arm.joints의 이름 순서입니다. 현재 손 치수·자세의 원본은 cad/modular_roots_v9/design.json입니다. 오래된 config의 손 질량/동역학 수치를 V9/V12 검증에 사용하면 안 됩니다.

보존된 V12·V13 후보 조립은 원본 CAD에서 수정 부품만 교체합니다. V9 생성기를 동결 폴더에서 다시 실행하면 감사 증거를 덮어쓸 수 있으므로, 재생성 실험은 복사본에서 수행합니다.

공식 모터 데이터의 세대·전압별 사양은 일치시켜야 합니다. 기존 config의 AK45-10 V3.0과 구동 대안 표의 baseline AK45-10은 동일한 SKU 검증이 완료되지 않았습니다. 최종 모터를 확정할 때 해당 도면/토크–속도 표로 다시 계산합니다.
