# WEBCAM004 정확 SHA 재검사와 사용자 시험

대상: `251358e5f2847ae09def226425defd3376e3e2b9`. 같은 에이전트가 Git archive로 만든 별도 깨끗한 사본에서 재실행했다. 독립 감사가 아니다.

- 코드46검사 통과. 동일한 로컬 개인 입력의789프레임 재생에서 구간 선정, 관절값/한계 비율, 인접 변화량, 손끝 잔차 및 입력/소스 해시가 원래 집계와 일치했다.
- 합성 앱121프레임 정상 종료. 미리보기 전후 비교도 다시 실행했으며 이 측정은 카메라·인식·창 표시를 제외한다. 검사 뒤 소스284파일이 변경되지 않았다.
- 실제 사용자 웹캠 시험은 주먹과 엄지가 여전히 어색하다는 결과였다. 수치 재현 통과를 자연스러움이나 해부학적 정확도 통과로 해석하지 않는다. 이후 기본 화면을 정면으로 바꿨고, 형상 우선이라는 사용자 지시에 따라 웹캠을 중지했다.

집계 증거: `clean_sha_review.json`, `clean_sha_tests.txt`. 개인 영상·원시 관절점·개인 보정값은 포함하지 않는다. 이번 후속 문서와 정면 초기 화면 변경은 위 대상 SHA에 포함되지 않은 후속 변경이다.
