# WEBCAM005 정확 SHA 재검사

대상: `c3d05a0783aaf7534297b2c3cebe7d4d317fa981`, origin/main 푸시 완료.

해당 SHA에서 필요한 코드·CAD 입력·검사 자료를 별도 빈 디렉터리에 git archive로 추출했다. 현재 작업 트리 코드를 import하지 않고 추출한 코드로 아래 검사를 실행했다. 숫자 재생의 개인 입력은 기존 로컬 로그에서 공급하고 원본 SHA256을 대조했다. 같은 에이전트의 별도 사본 검사이며 독립 감사가 아니다.

- 체크포인트 manifest26파일은 실행 전후 모두 일치했다.
- 전체61검사 통과. FORM002의132입력·124메시·20축·33자세 검사를 다시 통과했다.
- 같은1494저장행/195관측에서 전후 변화량, 관절별 범위, 부분 유지/기준 복구 수, 합성 필터 반응을 로컬 결과와 정확히 재현했다. 속도 측정은 환경 의존이므로 동일값 조건에 넣지 않았다.
- 합성 앱121프레임이 오류 없이 종료됐고 입력 소스 파일 변경이 없었다. 요약은 `exact_sha_result.json`에 있다.

실제 앱은 이 수정 코드로 카메라0에서 실행했다. 손 인식·편 손 보정 완료·주먹 보정 요청 이벤트가 확인됐다. 검사 시점 최근 손 관측의 카메라 수신과 처리율은 약14fps였으며, 이것을30fps 달성이나 사용자 품질 승인으로 표시하지 않는다. 실시간 카메라/화면과 입력 정확도는 여전히 평가 대상이다. 개인 보정과 원시 로그는 커밋하지 않았다.

잔여: 전체 최대 관절 튐, 가림의 실제 정답 부재, 원시 뼈 길이가 지속적으로 틀리지만 일정한 경우, 최초 좌우 분류가 모두 틀린 경우, 소지 PIP 가동 범위 감소. 이 후보는 해당 문제를 해결했다고 주장하지 않으며 추가 학습은 수행하지 않았다.
