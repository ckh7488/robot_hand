# WEBCAM001 커밋 후 새 사본 재검토

대상 SHA: `23c07bf0ddc0b734a888f1dd313da3b5be2ff96c`.
같은 에이전트가 수행한 재검토이며 독립 감사가 아니다.

Git archive로 대상 SHA의 `sim_3rd/hand_follow`, `cad/form_candidate_v1`,
저장소 규칙과 형상 기준 문서를 별도 새 디렉터리에 추출했다.
원본 작업 폴더의 Python 모듈이나 미커밋 CAD를 불러오지 않고, 새 사본의
테스트와 CAD 입력으로 동일한23개 검사를 실행해 전부 통과했다.
런타임 의존성만 같은 외부 Python3.12 환경을 재사용했다.

- 실제 STL120개를 scene의 SHA256과 대조하고 중립 위치·20축 연결을 재검사했다.
- 깊은 굽힘, 실제 공식 샘플 관절점, 엄지 계산과 MuJoCo 좌표 일치,
  좌우손·회전, 가려진 끝마디 보정·저장/재로드, 추적 소실과 필터를 재검사했다.
- 새 사본의 CAD에서 편 손·주먹을 다시 렌더링했다.
- 원본 실행 폴더에서는 전체 앱을 합성 입력으로2초 실행해61프레임 처리 후
  오류 없이 종료했다. 웹캠 창은 별도 프로세스로 계속 실행했다.

재검토 중 최신 실제 웹캠 세션에서 사용자가 수행한 C/V 보정이 각각 완료됐고,
검지 끝마디의 추정 사용이 명시적으로 기록됐다. 사용자 관절점·보정값·웹캠
로그는 로컬에만 보존한다. 최종 체감 추종 품질에 대한 사용자 응답은 아직
없으므로, 앞선 중간판의 엄지 문제 보고가 모두 해소됐다고 판정하지 않는다.

이번 결과는 기하 변환과 실행의 재현성 확인이다. 전체 동작의 CAD 간섭·
실물 제어·100ms 추종 성능·가려진 끝마디 독립 동작은 검증하지 않았다.
엄지 목표 오차와 표시된 추정 관절의 한계는 WEBCAM001에 명시했다.
