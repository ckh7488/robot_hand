# WEBCAM007 검토 근거

`local/preview_validation.json`은 원본 뼈대와 실제 화면 픽셀/카메라 축 검사, `local/capture_validation.json`은 동일 프레임 저장 검사다. `local/view_1.png`·`view_2.png`·`view_3.png`는 합성 입력으로 만든 화면이며 실제 사용자 손 정확도 자료가 아니다. 개인 사진과 좌표는 포함하지 않는다.

공통 검증은77단위검사다. FORM002 형상과 변환 알고리즘은 이 변경에서 수정하지 않았다. 원본 그림은 강체 회전/이동과 고정된 균일 표시 배율만 거치며, 세로 CAD 렌더도 종횡비를 보존한다. 이 작업의 목표는 원인 구분을 위한 표시이며 엄지/검지 오류 해결이 아니다.

정확 커밋SHA의 새 archive 사본에서 재검사한 결과는 별도 `exact_<sha>.json`과 설명으로 기록한다. 같은 에이전트의 별도 사본 검사로, 독립 감사라고 부르지 않는다.
