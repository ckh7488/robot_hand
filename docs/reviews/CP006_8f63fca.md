## 이번 회차의 판단

CAD에서 손바닥 모터 8개를 브래킷과 나사·너트로 어댑터까지 연결했다. 계산한 고정 손바닥 질량은 약32.1g 증가해 전체 약1.473kg이 되었고, 움직이는 20개 몸체와 관절 정의는 CP005와 같다. 따라서 기존 기본 동역학 29건의 수치가 CP005와 같은 것은 확인된 결과다. 이 회차에서 추종 성능이 개선되었다고 주장하지 않는다.

어댑터에서 기존 손바닥 섀시로 연결되는 8개 지지는 아직 없다. 모터 몸체가 어댑터에 고정된 것과 손 전체를 조립할 수 있는 것은 별개의 상태다. 도구 접근은 모듈 단위의 제한된 원통 검사이며, 바닥 나사를 먼저 조립해야 한다. 모터가 들어간 뒤에는 모듈당 바닥 나사 4개 중 2개의 검사 경로가 막힌다. 조립 전체의 너트 삽입·공구·커넥터 접근은 확인 전이다.

나사 CAD 형상과 공급사 파일의 파일럿 구멍 사이 8쌍×8.906415mm³의 겹침은 제한적으로 명시한 나사 체결 근사다. 나사산 형상·유효 물림·강도를 검증한 값이 아니다. 중립의 예상하지 않은 겹침 0개와 새 고정부품 40개↔움직이는 부품의 13자세 검사에서 0.01mm³ 초과 겹침 0개도 연속 전 범위 충돌 검사를 뜻하지 않는다.

엄지 진단에서는 중력·출력 제한·피드백의 상호작용이 큰 오차에 영향을 준다. 무중력이나 이상적 토크 진단에서 오차가 줄지만, 이 조건은 실제 모터 후보의 성능 증명이 아니다. 다른 축은 명령 유지 상태이며 고정·제거한 것이 아니다. 감쇠 진단은 선언한 자세의 고정 좌표 관성으로 계산했고, 실제 서보의 최적 이득을 찾았다고 읽지 않는다.

정지 45자세의 최대 중력 토크는 0.03687299Nm, 현재 모델의 영속도 전류 기반 토크 상한 근사는 0.10238095Nm이다. 이 샘플만으로 단순한 정지 유지 토크 부족이라고 판단하기는 어렵다. 다른 관절이 외부 힘으로 유지되는 정지 계산이고, 실제 연속 정격·전류 보정·속도 중 토크·가속·제동·열 여유는 검증하지 않았다. 급반전 중 큰 오차와 50/100ms 미충족은 여전히 해결 과제다.

125µs/62.5µs 비교에서 작은5°시험의 최대 차이는 0.01885331°로 선언 기준0.02°에 가깝다. 해당 시험의 추가 정착 상태80개는 일치했다. 급반전의 최대 차이는 1.175206°로, 전체 동작에0.1°정착 판정의 안정성을 보장하지 않는다.

## 다음 회차와 재현 범위

다음 CAD는 모터 위치·뿌리·손가락 길이를 유지하면서 8개 어댑터를 실제 손바닥 구조에 연결하는 지지를 구체화한다. [다음 지지 구조 검토](CP006_8f63fca_next_chassis.md)는 읽기 전용 후속 검토이며 새 CAD의 완료 기록이 아니다. 엄지 모터 체결과 실제 줄 접선·감김·장력 조절도 남아 있다. 동역학은 정지 토크만으로 모터를 교체하기보다 급반전의 속도·출력·제동·피드백 제한을 분리해 비교한다.

Windows 숨김 Python3.12, 저장소 밖 CadQuery2.8.0/OpenCascade7.9계열·MuJoCo3.3.7을 사용했다. 모든 재실행 출력은 검토 작업 사본 밖에 기록했다.

```text
python verify_audit_evidence.py --full
python tools/check_checkpoint.py --output <outside>/checkpoint.json
python tools/review_remote_checkpoint.py --geometry --simulation --model-frames --mount-sweeps --output <outside>/integration.json
python sim/remote_drive_v1/test_model.py --output <outside>/model_tests
python sim/remote_drive_v1/run_suite.py --output <outside>/simulation
python sim/remote_drive_v1/run_thumb_diagnostics.py --output <outside>/diagnostics --input-label checkpoint-clean-replay
python tools/screen_opposition_static_load.py --output <outside>/static_load.json
```

저장 STEP의 형상·질량·관성·연결축·체결과 13자세의 새 고정부품 교차를 다시 계산했다. 전체 CAD 생성과 중립280쌍 검사를 다시 생성한 것은 아니다. 그 중립 결과와255개 BRep 유효성은 체크포인트 생성 당시 기록이다. 전체 손의 연속 충돌·기계 강도·실제 줄 마찰·전원·열·실물 지연은 별도 검증이 필요하다.
