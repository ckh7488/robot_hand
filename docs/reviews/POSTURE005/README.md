## 해석과 남은 일

CAD·축·길이를 바꾸지 않고 각도·협응·이동 순서로 해결한 범위다. 오른쪽 새 목표는 빈손에서 약0.249mm 간격으로 손끝 앞면을 모으는 자세다. 이전 중앙 손바닥면 랜드마크 접촉과 목표가 다르므로 같은 파지 목표를 해결한 것으로 세지 않는다. 실제 접촉·물체 집기/유지는 미검증이다. 손가락을 따로 움직인 두 순서는 실패했고 함께 움직이는 경로가 이 표본 범위에서 통과했다.

반대 교차 방향은 미해결이며, 이것만으로 CAD 수정 필요를 확정하지 않는다. 사람다운 모습·자세·경로를 먼저 보존한다. 본 검사의 모든 탐색 조합·최적화 시작점·전체 경로 표본·앞덮개 지도99점·이전 물체 연구·그림 재렌더·연속 운동·공차·줄/모터·강도·실물 성능은 이번 재검토 범위가 아니다.

묶음 `reviews/audit.json`의 `unique_whole_pose_native_evaluations`는 초기 검사 하위 보고서에서 온 수다. 재교정 검사 수는 별도 `reviews/tip_refined.json`에 보존되어 있으며 두 작업 전체의 고유 자세 수로 합산/승계하지 않는다.
