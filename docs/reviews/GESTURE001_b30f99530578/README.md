# GESTURE001 커밋 후 핵심 재현

대상 커밋: `b30f9953057858a3ef3347f281cd12719ecc12d3`

해당 커밋을 별도의 깨끗한 D: 사본으로 내보내 manifest 1225개와 동결 증거222개를 확인했다. 전체 CAD 349개 부품을 입력부터 재생성했고, 부품별 체적·경계·질량·무게중심·관성 비교가 모두 허용오차 안에 들었다.

보·바위·엄지척의 실제 STEP 겹침 검사를 다시 실행해 원래의0건 결과를 재현했다. 공칭 체결 검사의 개별 결과 1519개도 모두 일치했다. 입력 소스와 재검사 실행기 자체의 해시는 실행 전후 동일했다.

이 재검사는 핵심3자세와 공칭 체결 범위다. 나머지6자세는 원래 체크포인트의 완료 검사에 남아 있으며 이번 깨끗한 사본에서 다시 실행하지 않았다. 전환 경로, 렌더, 동역학과 실물 공차·강도·100ms 지연을 검사한 것으로 확대하지 않는다. 같은 작업의 재현 확인이며 외부 독립 감사나 제조 승인이 아니다.

사용자 요청대로 이 단계의 그림과 결과를 보여준 뒤 추가 형상·성능 반복을 멈춘다.
