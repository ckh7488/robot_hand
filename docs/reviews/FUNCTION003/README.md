# FUNCTION003 · 정확 SHA 핵심 재현

대상 커밋: [6cc69e520dc92e30b9fe4fc2a4e30dcb1bad2e5a](https://github.com/ckh7488/robot_hand/commit/6cc69e520dc92e30b9fe4fc2a4e30dcb1bad2e5a)

정확히 이 커밋을 새 clone의 detached HEAD에서 읽고 입력부터 핵심 검사를 다시 실행했다. 같은 에이전트의 재검토이며 독립 감사가 아니다. 계산 실패나 남은 간섭을 성공으로 바꾸지 않았다.

- 저장 의존성1090파일과 동결222파일 해시 일치. `core.json`은 형상160파일을 확인했고, 추가 `frozen_hashes.json`은 같은 대상 SHA의 깨끗한 clone에서 형상160·코드38·보고서24파일 모두를 원래 동결 해시와 대조했다. 시작·종료 깨끗한 checkout, 입력 해시 가드 통과.
- 현재 손364부품 STEP 재수입 후 전체66066쌍 범위의 핵심 27표본을 재계산. 성공 자세뿐 아니라 수 표현 원래 실패, 새끼 굽힘·벌림, 네 손끝 집기·하트, 두 교차 방향의 실제 관통을 재현.
- 실행한 독립 굽힘/풀기4경로에서 중간점1개씩, 수정 수 표현의 원래/수정 끝자세와 접근/풀기5표본을 포함한다. 부품쌍 집합·연산 불확정 상태 및 겹침체적(차이허용1e−5mm³)을 비교해 차이0건.
- 접촉 후보6개의 저장 표면 랜드마크 간격·법선 방향을 현재 관절 프레임으로 다시 계산해 일치.

## 개수와 해석

기능 검사59항목은 서로 다른 수치 자세57개다. 열린 손/다섯 수 표현과 검지 접촉/OK는 각각 같은 각도로 두 기능 목표를 검사한 항목이다. 간섭19항목은 서로 다른 수치 자세18개에 해당한다. 이름만 다른 항목을 추가 성공 동작으로 세지 않는다. 기존 본 검사 결과 JSON은 원래대로 보존한다.

검지만 펴는 동작은 기존3쌍 겹침을 엄지 자세·순서로0으로 수정했고 원래79경로표본에서 보고 기준 이상 겹침0이다. 이 재검토는 전체79표본을 반복하지 않고 저장 중간점5개와 두 끝자세를 재현했다. 본 검사의59항목·4경로100표본 전체, 모든 최적화 시작점, 그림 재렌더,33개 물체 파지·연속 경로·강도·구동·실물 성능은 재검토 범위가 아니다.

보고 기준은 재료 겹침0.02mm³ 초과, Boolean 허용오차1e−6mm이다. 기능·제작·실물 승인은 없으며 가까운 교차와 집기는 미완이다. 다음은 전체 부품 간섭을 고려한 대립/교차 후보와 실제 물체 접촉·접근·놓기 검사다. 작은 여유 미달을 먼저 다듬는 반복으로 되돌아가지 않는다.
