# DRIVE002 커밋 후 새 사본 재검사

대상: `661e19ced68b64daefd0600060219c84fc0a0694`. 해당 커밋의 추적 파일을 새 D: 폴더에 추출하고 Git blob·체크포인트 manifest·동결 증거 222개를 확인했다. 원래 작업 폴더의 미커밋 파일을 입력으로 사용하지 않았다.

**재현 검사 통과.** CAD를 다시 만들고 190부품의 질량·전체 관성·형상 대응, 편 손·주먹·검지 벌림 충돌 반례, 뿌리 핀·좌면·체결 검사를 다시 계산했다. 새 동역학 입력을 다시 만들고 실제 형상/관성 13개 검사와 시험 규약 5개 검사도 다시 실행했다. 반례의 남은 충돌을 포함한 기존 결과가 선언한 수치 오차 안에서 재현됐다는 뜻이다.

이번 재검사는 4건의 동역학 적분, 주먹 경로 전체 13표본, 기존 모터 배치 간섭, 렌더를 다시 실행하지 않았다. 이 결과들은 커밋의 해시로 보존만 확인했다. STEP 파일의 저장 시각에 따른 바이트 차이는 허용하되 실제 부품의 체적·질량·무게중심·관성과 자세별 충돌 결과를 비교했다.

이는 같은 작업에서 만든 새 사본 재검사이며 외부 독립 감사가 아니다. 제작 승인, 연속 경로의 무간섭, 실제 구동계 통합 또는 100ms 실물 성능 승인으로 해석하지 않는다.

세부 비교·실행 명령·환경·실패 보존·시작/종료 해시는 [review.json](review.json)에 기록했다.
