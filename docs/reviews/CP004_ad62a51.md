## 실행 범위

Windows, Python 3.12, CadQuery 2.8.0/OpenCascade 7.9 계열, MuJoCo 3.3.7에서 저장소 외부 의존성을 사용했다. 숨김 Python 프로세스로 실행하고 출력은 작업 사본 밖에 저장했다.

```text
python verify_audit_evidence.py --full
python tools/check_checkpoint.py --output <outside>/checkpoint.json
python tools/review_remote_checkpoint.py --geometry --simulation --model-frames --output <outside>/integration.json
python sim/remote_drive_v1/test_model.py --output <outside>/model_tests
python sim/remote_drive_v1/run_suite.py --output <outside>/simulation
```

이번 커밋 후 검토는 저장 STEP의 정밀 재수입·질량/관성 재측정과 전체 동역학 재계산이다. CAD 전체 생성기 및 정적 교차 Boolean 검사를 처음부터 재생성하지 않았고, 연속 충돌·실제 줄 감김·체결·강도·하드웨어는 검사하지 않았다. 기준 V9의 6개 자세/251부품 및 이전 배선 곡선 기본 검사는 자료 보존 확인이며 새 구조의 전체 가동 범위 검증으로 쓰지 않는다.

## 후속 과제

첫 개선은 엄지 MCP의 실제 부모 포크 축과 35° 돌아간 자식 축을 맞추고, 손바닥의 모터·스풀·고정판 실체 겹침을 줄이는 것이다. 형상이 바뀌면 CAD 질량·관성과 전체 동역학을 다시 계산한다. 줄 경로는 공간 표시 단계이므로 실제 접선·감김·장력 조절과 간섭을 별도로 설계해야 한다.

동역학의 모터 PD·전류 제한·마찰·강성은 실물 보정 전 가정이다. 일부 사건의 작은 지연값이나 구형 모델 대비 오차 감소만으로 50/100ms 또는 모터 선정 결론을 내리지 않는다. 작은 동작에서의 선행/누락 분류, 엄지 이동 모터의 중력 부하와 급반전 출력 제한을 후속 회차에서 분리해 조사한다.

추가 코드 검토에서 두 가지 평가 한계를 확인했다. 현재 6개 동작의 명령은 이미 DIP=0.8×PIP 관계이므로 16축 비교는 독립 자세 표현 손실을 시험하지 않는다. 또한 작은 동작의 일부 축은 0.6~1° 진폭인데 정착 오차 띠는3°여서, 정착했다고 작은 동작을 재현했다고 해석할 수 없다. CP005 이후에는 독립 PIP/DIP 명령과 진폭을 고려한 정확도 기준을 추가하고, 선행 통과·기존 오프셋·실제 미도달을 구분한다. CP004의 원시 궤적과 실패 기록은 그대로 보존한다.
