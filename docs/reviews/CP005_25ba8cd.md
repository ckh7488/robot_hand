## 해석과 남은 제약

새20축의 독립 원위 동작은 사건 최대 시차 약8.03ms를 보였다. 그러나 최대 자세 오차는 약2.45°이고, 추가 정착 기준은80개 중57개 구간에서 충족하지 못한다. 실패 중57개는 움직이지 않도록 명령한 축의 구간이며, 움직이는 축은20개 중20개 구간이 진폭에 비례한 정착 띠를 충족했다. 임시0.1°유지 기준과 움직이는 축의 지연을 같은 실패로 설명하지 않는다.

16축 같은 시험은 연동 가능한 목표를 잘 따라가도 요청한 독립 자세를 최대60°잃는다. 가상16축의 사건 통과를 원래 요청 자세 재현으로 바꾸어 쓰지 않는다. 다른 시험 중6개 새20축 시험에는 사건 판정 미충족이 남고 급반전의 큰 오차도 해결되지 않았다.

작은5° 명목 시험의 시간간격 차이는0.02°기준에 가깝다. 급반전의 최대 시간간격 차이는1.17521°다. 이번 검사가 모든 동작·민감도에서0.1°정착 판정의 안정성을 증명하지는 않는다. 모터 PD·전류-토크·마찰·강성은 실물 보정 전 가정이고 기본 제어 이득은 이 회차에서 바꾸지 않았다.

현재 손바닥 고정판에는 실제 섀시로 힘을 전달할 지지대·체결이 필요하다. 엄지 받침대의 체결·강도·축 고정, 줄 접선·감김·장력 조절·벌림 보상, 전 가동 범위 간섭·배선·전원·열·실물 계측도 남아 있다. 검토 JSON의 빈 기구 결함 목록은 명목 연결축 결함이 없다는 뜻에 한정되며 조립 승인으로 읽지 않는다.

추가 형상 검토에서는 손바닥의 새 고정판과 모터 사이에1.5mm 틈이 있고, 기존 모터 몸체 체결축과 판의 구멍 방향이 다름을 확인했다. 다음 CAD 회차는 모터 몸체를 잡는 크래들의 실제 체결부터 설계한 뒤 크래들·고정판에서 손바닥 섀시로 이어지는 지지를 만든다. 위치·기존 섀시 후보 근거는 [다음 고정 구조 검토](CP005_25ba8cd_next_mounts.md)에 남긴다. 제안한 지지 위치의 강도·공구 접근·실제 조립은 아직 검증하지 않았다.

반경 비교는 실제 풀리·스풀·전달 계약·회전 관성을 함께 갱신해야 한다. 큰 오차가 발생한 엄지 대립축은 직접 구동이므로 원위 스풀 반경 변경이 그 축을 직접 감속하지 않는다. 제어기 가정과 전압·전류 제한·출력 상승을 분리할 제한된 진단 순서를 [다음 동역학 검토](CP005_25ba8cd_next_dynamics.md)에 기록했다. 이 후속 메모는 읽기 전용 검토이며 새로운 CAD나 성능 계산의 완료 기록이 아니다.

## 재현 범위

Windows의 숨김 Python 프로세스, 저장소 외부 의존성(Python3.12, CadQuery2.8.0/OpenCascade7.9계열, MuJoCo3.3.7)을 사용했다. 결과·로그는 작업 사본 밖에 기록했다.

```text
python verify_audit_evidence.py --full
python tools/check_checkpoint.py --output <outside>/checkpoint.json
python tools/review_remote_checkpoint.py --geometry --simulation --model-frames --output <outside>/integration.json
python sim/remote_drive_v1/test_model.py --output <outside>/model_tests
python sim/remote_drive_v1/run_suite.py --output <outside>/simulation
```

저장 STEP의 실제 형상·질량·관성·연결축을 재측정하고 전체 동역학을 재계산했다. 전체 CAD 생성·중립 교차 Boolean을 새로 재생성하지는 않았다. 중립161개 후보쌍의0개 겹침은 체크포인트 생성 당시 결과이며, 연속 충돌·실제 줄 전달·제작·하드웨어 시험을 대신하지 않는다. 전체 실체 경계는 약250.895×407×101mm로 CP004보다 가로6.813mm 증가했다.
