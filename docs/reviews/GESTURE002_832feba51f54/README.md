# GESTURE002 커밋 후 핵심 재현

대상 커밋: `832feba51f54be5a4300da6a53dcbc56505ec98c`

해당 커밋을 별도의 깨끗한 D: 사본으로 내보내 manifest 1239개와 동결 증거 222개를 확인했다. 전체 CAD 349개 부품을 입력부터 재생성했고, 부품별 체적·경계·질량·무게중심·관성 비교가 모두 선언된 허용오차 안에 들었다.

보·바위·엄지척의 실제 STEP 겹침 검사를 다시 실행해 원래의 부품쌍과 겹침 부피 판정을 재현했다. 재검사한 세 자세의 보고 기준 초과 겹침은 자세별 합산 0건이다. 공칭 체결 검사의 개별 결과 1519개도 모두 일치했다. 결과의 일치는 남아 있는 기하·제작 실패를 통과로 바꾸는 뜻이 아니다.

보→바위, 보→엄지척, 바위→엄지척의 커밋된 `core_paths.json`과 원래 2.5° 보고서의 **전체 표본**을 연결해 구간·비율·각도 배열의 산술 대응을 대조했다. 새 CAD 재검사는 세 경로 각각의 진행 비율 0·0.25·0.5·0.75·1에 가장 가까운 기존 표본과, 보→엄지척·바위→엄지척의 작성된 경유점 네 개씩을 골랐다. 거리 동률은 앞 표본을 고르고, 기록된 각도를 재계산하거나 반올림하지 않은 채 동일 각도를 정확한 부동소수점 값으로 중복 제거한 **14자세**를 새 STEP에서 검사했다. 재검사한 선택 표본의 보고 기준 초과 겹침은 표본별 합산 0건이며, 원래의 부품쌍·부피 판정이 재현됐다. 이는 **대표 전환 표본의 정확한 재현(selected transition samples exact replay)**이다.

이는 앞서 완료한 원래 전체 경로 검사를 축소한 것이 아니라 그 뒤의 커밋 후 대표 재현이다. 주먹 경로의 33경유점 및 전체 2.5° 전환 표본을 CAD에서 모두 다시 계산하지 않았다. 역방향 경로, 나머지 여섯 끝자세, 최소거리, 렌더, 동역학도 이번 깨끗한 사본에서 다시 실행하지 않았다. 입력 소스와 재검사 실행기의 해시는 실행 전후 동일했다. 표본 사이의 연속 간섭, 실물 공차·강도·100ms 지연, 제작 가능성을 승인하지 않는다. 같은 작업의 재현 확인이며 외부 독립 감사가 아니다.

이번 단계의 자세·동작 그림과 검사 범위를 보여준 뒤 결과를 정리한다. 추가 형상·성능 개선이나 실물 동작을 실행한 기록은 아니다.
