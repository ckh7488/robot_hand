# 빨간 표시의 의미와 사람다운 손모양 조건

이전 빨강은 겹침이 발생한 부품 전체 색칠이어서 실제 문제보다 넓게 보였다. 새 그림의 빨간 원은 저장된 실제 재료 겹침의 중심 위치 표시다. 원 크기가 겹친 체적 크기는 아니다.

해당 교차/집기 후보 자세에서는 재료가 겹쳐 걸리지만, 손 전체의 근본 설계 결함이나 큰 외형 수정의 필요가 확정된 것은 아니다. 먼저 자연스러운 자세와 접근/풀기 순서로 해결한다. 사람 손 같은 비율·모양·협응을 유지하며 관절 끝에 기대어 접촉 수치만 맞추는 부자연스러운 후보는 채택하지 않는다.

기존364부품과 관절축·길이는 이번 설명 수정에서 바꾸지 않았다. 물체 접촉의 진행 중 탐색은 별도 미완 연구이며 자연스러운 잡기나 실물 동작으로 승인하지 않는다.
