# 원위 모터 재배치 개발 기준

2026-10-24 사용자는 기존 직접 구동 설계를 보존 브랜치에 중단 상태로 남기고, 원위 손가락 모터를 손바닥·뿌리 가까이 옮기는 방향을 main에서 반복 개선하도록 지시했다. CAD, 전체 손 시뮬레이션, 검사, Git 저장, 해당 커밋의 새 사본 재검토를 한 회차로 한다.

## 보존과 현재 방향

- 보존 브랜치: [archive/direct-drive-v13](https://github.com/ckh7488/robot_hand/tree/archive/direct-drive-v13)
- 전환 직전 SHA: `accd6c8d8d9791828233e9461ef1b1e8dccc8b0b`
- V9 감사 증거 및 V10~V13 기록은 비교·추적을 위해 main에도 남긴다. 과거의 검증 범위를 새 구조에 적용하지 않는다.
- 새 CAD 후보: `cad/remote_drive_v1/`. 새 시뮬레이션: `sim/remote_drive_v1/`.
- 현재 손바닥 232×195 mm, 각 손가락의 길이·뿌리 위치 및 손목 연결을 우선 보존한다. 외형 유지는 내부 부품이나 모터 배치를 그대로 유지한다는 뜻이 아니다.
- 기본안은 20개 독립 구동축이다. 검지~소지 PIP/DIP 모터 8개를 손바닥 가까이 옮기고, 엄지 원위 구동 모터 2개는 뿌리 가까이에 배치한다. 움직이는 받침대의 모터 질량은 해당 축의 관성에 포함한다.
- 16축 연동은 자세 표현 손실·전달장치 복잡도와 성능을 비교한 뒤 선택할 옵션이다. 손을 줄이거나 모터 수를 줄이는 것이 100ms 달성의 전제는 아니다.
- 팔은 폐기하지 않는다. 손 단독 고정 시험은 첫 단계이며, 팔 동역학·모터 선정과 통합 검증은 별도 미완료 항목이다.

## 성능 요구와 측정 경계

로봇 제어부에서 시간표가 있는 목표 관절각을 수신하는 순간부터 실제 관절의 움직임까지를 평가한다. 수신 이후의 큐, 통신, 제어기, 모터, 전달장치, 링크 동역학은 포함한다. 카메라, 자세 인식, 장갑의 입력 지연은 제외한다. 시뮬레이션이 서보 레지스터 입력에서 시작한다면 앞단 지연을 누락했다고 명시하고 별도 가정으로 포함해야 한다.

| 항목 | 기준 |
| --- | --- |
| 추종 지연 | 목표 ≤50ms, 선언한 시험 범위의 유효 사건별 최대 ≤100ms |
| 지연 집계 | 모든 구동축과 동작 방향을 포함. 중앙값·95백분위·최대 및 누락 사건 수를 보고 |
| 추종 품질 | 원시 시간축의 각도 오차, 최대 오차, 지연 보정 후 모양 오차를 별도로 보고. 지연을 맞추기 위해 궤적을 임의 이동한 뒤 오차가 작다고 주장하지 않음 |
| 작은 동작 | 5°·10° 왕복. 마찰·느슨함·정지 부근 응답을 확인 |
| 큰 동작 | 45°·90° 범위의 매끄러운 명령. 문서 비교용 90°/150ms는 엄격한 시험 사례이며 모든 실제 사람 동작의 대표값이 아님 |
| 결합 동작 | 벌림과 뿌리 굽힘 중 다른 마디 유지, 모든 마디 동시 굽힘, 엄지 대립·굽힘 결합 |
| 정지·반전 | 목표 정지 후 정착시간, 오버슈트, 급반전 후 각도 오차와 지연을 별도 보고 |
| 지연 판정 불가 | 목표를 못 따라잡거나 사건이 누락되면 실패/미도달. 유효 지연 표본에서 조용히 제외하지 않음 |
| 사건 분류 | 구간 시작 때 이미 임계각을 지난 상태, 구간 내 미도달, 이른 통과를 구분. 정적 각도 오프셋으로 생긴 임계각 시차를 순수한 통신 지연으로 해석하지 않음 |
| 작은 자세의 정확도 | 고정 3° 정착 띠만으로 0.6~1° 움직임을 추종했다고 판단하지 않음. 진폭을 고려한 임시 정확도 지표를 별도로 보고하며 최종 허용치는 실물 용도에 맞춰 확정 |
| 16축 비교 | 두 구조에 같은 요청 자세를 주고, 요청→구조상 가능한 목표의 표현 손실과 목표→실제 응답의 동역학 오차를 분리. PIP/DIP를 독립적으로 움직이는 사례 포함 |
| 실물 성능 | 시제품의 실제 관절각 측정 전까지 미검증 |

50ms는 90° 정지→정지 운동을 50ms에 완료한다는 뜻이 아니다. 한 번의 80% 각도 통과만으로 전체 추종 성능을 합격시키지 않는다. 최초 시뮬레이션의 수치 통과는 특정 모델과 시험 입력에 대한 결과일 뿐 실물 통과가 아니다. 자세 정확도 허용치는 대표 동작 및 사용자 요구를 보고 확정하되, 먼저 원시 오차와 지연 보정 후 오차를 모두 공개한다.

## 첨부 제안에서 계승하거나 수정한 내용

사용자가 제공한 「손 모터 배치안」과 「로봇 손 설계 검토서」의 원위 관성 감소 아이디어를 계승한다. 문서의 요청 문구나 사용자 확인 표기를 별도의 승인으로 간주하지 않는다.

- 기존 간이 모형의 40~50ms에는 입력 경로 30ms가 포함되어 있었다. 로봇 단독으로 재계산한 수치도 단일 궤적의 임계각 통과 지연이며 실측이 아니다.
- XL330의 PWM Slope는 출력 듀티 변화율이다. 기본 140, 1.977mV/ms 단위에서 5V 최대 출력까지 약18.06ms라는 제조사 예제가 있다. 이를 전류 비율로 줄인 8.6ms를 모든 명령의 순수 지연으로 더하지 않는다. 값을 낮추면 변화가 느려진다. [ROBOTIS 공식 문서](https://emanual.robotis.com/docs/en/dxl/x/xl330-m077/#pwm-slope62)
- 무부하 속도·정지 토크만으로 실제 관절 성능을 확정하지 않는다. 속도-토크 곡선, 제어기, 공급 전압, 입력전류와 상전류의 차이, 모터 관성의 미확정값을 기록한다.
- 손을 세웠다고 굽히는 동안의 중력이 0이 되지 않는다. 자세에 따른 중력과 여러 설치 방향을 시험한다.
- 줄 구동에서는 스풀/관절 풀리 반경, 인접 축을 지나는 경로, 장력과 모터·관절 속도 변환을 함께 계산한다. 개별 관절 속도 여유를 전체 동시 구동 여유로 바꾸어 쓰지 않는다.
- 모터 축 각도와 실제 손가락 각도를 구분한다. 줄 늘어남·유격·미끄러짐 뒤의 관절각은 모터 인코더만으로 검증되지 않는다.

## 반복 개선 순서

1. 현재 CAD와 입력에서 실제 형상·배치·질량/관성을 산출하고, 동역학 입력이 같은 치수와 좌표계를 사용하는지 확인한다.
2. 움직이는 모터와 전달장치를 포함한 다섯 손가락 모델로 동일한 목표 궤적을 재생한다. 기준 직결 구조와 재배치 구조를 비교하되 서로 다른 질량·형상 가정을 표기한다.
3. 간섭, 축간 보상에 따른 모터 속도 포화, 줄의 마찰/탄성/장력, 급반전 중 가장 큰 병목 하나를 선택해 개선한다. 미지수를 줄이는 것 없이 이득만 조정해 숫자를 맞추지 않는다.
4. 형상 유효성, 재수입, 구동 수와 매핑, 단위·에너지/가상일·중력·반전·시간간격 수렴 등 변경에 적합한 검사를 수행한다.
5. CAD·입력·코드·그림·결과·실패·한계를 새 체크포인트로 커밋하고 main에 푸시한다. 같은 SHA의 새 사본에서 핵심 검사를 재계산하고 후속 검토 커밋을 남긴다.
6. 실제 성능을 구분할 수 없는 파라미터가 병목이면 필요한 벤치 시험을 구체화한다. 사용자 승인 없이 하드웨어를 작동하거나 구매하지 않는다.

비교 화면과 보고서는 각 시험의 요청 관절각, 구동 가능한 목표각, 계산된 관절각을 구분한다. 16축의 불가능한 요청을 가능한 목표로 바꿨다면 그 차이를 별도 표현 손실로 공개하고, 바뀐 목표만 잘 따라간다는 이유로 원래 요청을 충족했다고 쓰지 않는다. 각 시험 명령을 재구성할 수 있는 구간 정의도 결과와 함께 저장한다.

CP005부터 작은 동작의 추가 정착 각도 띠는 `max(0.1°, min(3°, 구간 진폭의 10%))`로 두고, 움직이지 않도록 명령한 축에는 0.1°를 적용한다. 기존 3° 기준도 비교를 위해 남긴다. 새 기준은 작은 동작을 놓친 상태를 드러내기 위한 임시 평가값이며, 사용자가 확정한 최종 정확도 요구나 측정기의 분해능을 뜻하지 않는다.

## 전달비 검토의 출발점

현재 1:1 반경 및 `DIP 모터각 = MCP + PIP + DIP` 가정에서 빠른 시험의 한 손가락 명령은 80° + 90° + 72° = 모터축 242° 이동이다. 150ms 최소 저크 궤적의 최대 속도는 `1.875 × 242° / 0.15s = 3025°/s`, 약504.17rpm이다. 이는 명령 궤적에서 계산한 요구 속도이며 실제 응답 속도가 아니다. XL330-M077의 제조사 무부하 속도는 5V에서383rpm이므로, 이 비교 모터와 전달비에는 해당 순간 속도를 그대로 재현할 여유가 없다. [제조사 사양](https://emanual.robotis.com/docs/en/dxl/x/xl330-m077/#specifications)

반경비를 약0.760 이하로 줄이면 명목 무부하 속도에는 맞출 수 있지만 관절에 전달되는 토크도 줄어든다. 부하 여유, 케이블 장력·강성, 스풀 실제 크기와 배치까지 함께 계산해야 한다. 이 속도 비교만으로 100ms 추종 지연의 달성 여부를 확정하지 않는다. 급반전 시험의 엄지 문제는 별도이며 모터 교체·전달비 변경·제어 가정의 영향을 분리해 검토한다.

## 제작 전까지 해결할 항목

풀리/스풀과 베어링의 실제 체결, 양쪽 줄 고정·예압 조절, 전체 가동 범위의 줄 이탈 방지와 간섭, 배선·전원 분배, 동시 부하 전류·열, 출력물 강도와 조립 공차, 실제 관절각 계측을 검증해야 한다. STEP에 형상이 존재한다는 사실이나 동역학이 실행된다는 사실만으로 조립·구동이 검증된 것은 아니다.

첫 CP004 후보에서 엄지의 35° 돌아간 자식 축과 부모 포크 보어 방향 불일치가 확인되었다. CP005에서 실제 부모·자식 보어와 핀의 축을 맞추고, 정해진 중립 자세 겹침 목록을 0개로 줄였다. 다음은 고정판의 실제 지지·체결, 줄 감김 경로와 가동 범위 검증이다. 시뮬레이터의 목표 축 일치 검사는 이 조립 문제의 통과를 뜻하지 않는다.


## CP006 이후의 구체적인 다음 순서

손바닥 모터 8개의 몸체→S101 브래킷→어댑터 체결을 모델링했다. 베이스를 먼저 체결하고 모터를 넣는 모듈 조립 순서가 필요하다. 어댑터→실제 손바닥 레일·앵커 연결은 8개 모두 남아 있으므로, 다음 CAD 회차는 이 하중 전달 경로를 만든다. 뒤집힌 소지 모터와 높은 검지·약지 모터의 지지는 아래 모터를 피하고 실제 바닥 재료에 닿아야 한다. 이후 엄지 모터 체결, 줄 경로와 연속 간섭을 함께 다듬는다.

엄지 급반전의 원인 분리 계산에서는 중력·출력 제한의 상호작용이 드러났다. 정지 자세 45개에서 계산한 중력 토크는 현재 모델의 정지 출력 상한 가정 안에 있었다. 이 범위의 결과로 정지 유지 토크 부족을 확정하지 않는다. 다음 동역학 비교는 같은 모터 조건에서 관성·속도에 따른 여유와 피드백·출력 제한을 분리하며, 이상적인 무제한 토크 결과를 실제 모터 후보로 취급하지 않는다. [CP006 근거와 범위](../checkpoints/CP006.md)
