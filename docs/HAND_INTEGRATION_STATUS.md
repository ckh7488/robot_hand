# 손쪽 통합 상태와 작업 범위

2026-10-27 사용자 수정: 팔꿈치까지 전기 배선을 확장하기 전에 손쪽의 모터·전선·구동 전달계를 먼저 정리한다. **현재 손은 실제 구동 가능한 통합 완성품이 아니며 전체 무충돌을 확인하지 못했다.** 기존 CAD/실패/검토 기록은 보존한다.

## 확인한 것과 남은 것

| 항목 | 확인한 범위 | 아직 남은 핵심 |
| --- | --- | --- |
| 손의 움직임 | 같은364부품의 일부 대표 손동작 끝자세와 접근/풀기 표본 경로 | 모터·전선·전달계까지 넣은 전체 운동 검증은 아님 |
| 모터 배치/고정부 | 손바닥4/원격16의 명목 배치 후보. PALM014/MOUNT015의5끝자세 정적 공간·조건부 조립 | 전체20모터 설치·체결/강도·실제 힘 전달 승인 아님 |
| 손쪽 전선 | 원격48리드의 고정 출구 공간. 손바닥12선은 가정 외곽의 작은 겹침으로 미채택 | 실제 케이블/커넥터 치수·고정/당김 방지·움직임 중 끼임/쓸림 |
| 구동 전달부 | 모터/출력 드럼의 참고 외형과 과거 국부 연구 | 현재 손의 모터 출력→허브/풀리·구동줄→손가락 연결/구속·장력·통합 경로 미완 |

현재 배치의 [설치 변환/전달계 상태](../cad/palm_motor_layout_v1/selected/generated/layout.json)는 각 모터의 오프셋 양방향 당김 전달과 관절 연결을 미완으로 명시한다. 출력 드럼은 회전자 앞과0.5mm 떨어진 참고 형상이며 허브/혼 결합이 설계되지 않았다. **이0.5mm는 임의 간격 기준 미달 문제가 아니라,실제 토크를 전달하는 연결이 아직 없다는 상태 설명이다.** 벨트 같은 전달부까지 모두 연결해 검증한 완성 구동계로 해석하지 않는다.

[MOUNT015](../cad/palm_motor_mount_v1/README.md)의 받침/조립 후보와 [PALMLEAD016](../cad/palm_motor_lead_v1/README.md)의 미채택 손바닥 전선 범위를 그대로 유지한다. 손바닥 전선의 미확정 외경/굴곡에 따른 작은 겹침은 손 절삭이나 구조적 불가능의 근거가 아니다. 실제 공급 하네스/출구 치수를 확인한다.

## 다음 작업 순서

1. 현재 모터부터 손가락까지 실제 힘 전달 연결을 추적해 빠진 허브/풀리·줄 고정/가이드와 구속을 정리한다. 필요한 대표 관절부터 실제 CAD로 연결해 검사하고 확장한다. 참고 드럼이 배치되어 있다는 이유로 구동 연결 완료로 세지 않는다.
2. 손쪽 전선/커넥터의 실제 치수와 배치를 확인하고 고정·관절 여유·끼임/당김을 검사한다. 작은 가정 치수 미세 최적화로 돌아가지 않는다.
3. 통합 후보를 대표 잡기/풀기·교차·독립 굽힘 경로에 넣고 새 부품과 줄/전선의 실제 간섭·이탈/막힘을 확인한다. 자연스러운 자세/순서로 해결할 수 있으면 먼저 채택한다. 기존 손의 기구학 영상은 모터 구동이나 유연 케이블 해석의 증거가 아니다.

기존 전완16원격모터는 손 구동원이므로 삭제하거나 검토에서 제외하지 않는다. 손 기능에 필요한 그 모터부터 손목/손가락까지의 구동 경로는 범위 안이다. **팔꿈치 방향의 긴 전기 배선·보드 종단 확장은 뒤로 미룬다.** [BUS017](../cad/remote_bus_v1/README.md)의 두 선 묶음/임시 종단 연구는 별도 보존하며 손쪽 완료 근거나 현재 필수 설치 부품으로 자동 승계하지 않는다.

손쪽의 명목 배치/구동 연결이 적당히 통합되면 요청한3~4손동작을 그 후보 구성으로 보여준다. 공급품·실물 성능 전체 검증을 기다리며 영상을 무기한 미루지는 않되,영상/검사의 실제 범위와 미완을 명시한다. 물리 모터 작동·전원 인가·구매는 하지 않는다.

## DRIVE018 진행 범위

[대표 엄지 IP 모터 출력부](../cad/motor_spool_coupling_v1/README.md)에 기존 출력 원판을 유지하고 나사4개·두 줄 홈/고정부가 있는 드럼을 연결했다. 회전 중 새 드럼 돌출부/기존 어댑터 걸림은 일체형 연결 목으로 교정했으며 손/모터/전선 위치는 유지했다. 선택 후보는새10+유지358=368포장행이며 회전자 원본3솔리드를 분리한 참조3행을 포함한다. 새7맞춤 부품의 전 회전각 공간/6끝자세와 조건부 삽입 공간을 확인했지만,손목~손가락 두 줄 연결/장력·실제 공급 나사/공구·강도·전체 통합 운동은 미완이다. 기존 모터 내부 참고 나사 접촉도 보존하며 실물 승인으로 쓰지 않는다.

## TENDON019 진행 범위

[대표 엄지IP 두 줄 경로](../cad/thumb_tendon_route_v1/README.md)를 모터~손목~기존 손끝 고정부까지 실제 튜브 CAD로 만들었다. 손/모터/받침/기존48전기선은 그대로다. 편 손/IP45°의 줄 공간은 통과했지만 부모와 함께 굽힌4자세는 엄지 뿌리 외피에 걸려 전체 경로는 미채택이다. 곡선의 굽힘 중심도 몸체에 대해 최대11.612929mm 변하므로 실제 고정 가이드로 세지 않는다. 줄 길이 공통 변화·가이드 축/지지·예압/미끄럼/실물 구동은 미완이며 손을 깎을 근거로 쓰지 않는다. 다음은 실제 가이드와 구속을 설계한 뒤 같은 자연스러운 자세에서 통합 경로를 재검사한다.
