# 손쪽 통합 상태와 작업 범위

2026-10-27 최신 사용자 지적: 현재 큰 외부 구조와 모터 집중 배치가 손목·팔꿈치·전완 회전을 막지 않는지, 전체 팔 배치부터 재검토한다. 현재 손바닥4/원격16은 미확정 배치이며, 국부 검사를 위해 랙 위치를 고정한 조건은 배치 수용이 아니다. 원격16은 두 열·여덟 위치의 긴 랙에 놓인 명목 후보이고 랙 Y범위−339~−1mm가 기존 전완 회전축 Y−230mm의 앞뒤에 걸친다. 이는 관통 판정이 아니라 관절별 부착 몸체와 회전 공간을 먼저 풀어야 한다는 근거다. 실제 전체 연결 상태에서 손목·팔꿈치·전완 회전을 함께 검사하지 않았으므로 가능/불가능을 확정하지 않는다. 국부 선 경로 확장과 다른 축 복제에 앞서 이 구조 검토를 진행한다.

2026-10-27 사용자 수정: 팔꿈치까지 전기 배선을 확장하기 전에 손쪽의 모터·전선·구동 전달계를 먼저 정리한다. **현재 손은 실제 구동 가능한 통합 완성품이 아니며 전체 무충돌을 확인하지 못했다.** 기존 CAD/실패/검토 기록은 보존한다.

## 다음 작업 순서

1. 현재 모터부터 손가락까지 실제 힘 전달 연결을 추적해 빠진 허브/풀리·줄 고정/가이드와 구속을 정리한다. 필요한 대표 관절부터 실제 CAD로 연결해 검사하고 확장한다. 참고 드럼이 배치되어 있다는 이유로 구동 연결 완료로 세지 않는다.
2. 손쪽 전선/커넥터의 실제 치수와 배치를 확인하고 고정·관절 여유·끼임/당김을 검사한다. 작은 가정 치수 미세 최적화로 돌아가지 않는다.
3. 통합 후보를 대표 잡기/풀기·교차·독립 굽힘 경로에 넣고 새 부품과 줄/전선의 실제 간섭·이탈/막힘을 확인한다. 자연스러운 자세/순서로 해결할 수 있으면 먼저 채택한다. 기존 손의 기구학 영상은 모터 구동이나 유연 케이블 해석의 증거가 아니다.

기존 전완16원격모터는 손 구동원이므로 삭제하거나 검토에서 제외하지 않는다. 손 기능에 필요한 그 모터부터 손목/손가락까지의 구동 경로는 범위 안이다. **팔꿈치 방향의 긴 전기 배선·보드 종단 확장은 뒤로 미룬다.** [BUS017](../cad/remote_bus_v1/README.md)의 두 선 묶음/임시 종단 연구는 별도 보존하며 손쪽 완료 근거나 현재 필수 설치 부품으로 자동 승계하지 않는다.

손쪽의 명목 배치/구동 연결이 적당히 통합되면 요청한3~4손동작을 그 후보 구성으로 보여준다. 공급품·실물 성능 전체 검증을 기다리며 영상을 무기한 미루지는 않되,영상/검사의 실제 범위와 미완을 명시한다. 물리 모터 작동·전원 인가·구매는 하지 않는다.
