# Robot Hand

**사람의 손과 팔 움직임을 빠르게 따라 하는 3D 프린트 로봇을 만드는 프로젝트입니다.**

현재는 **원래 손의 비율·마디·손끝·엄지 형태를 유지하면서** 움직이는 손가락을 가볍게 하는 구조를 개발합니다. 손가락20축의 독립 제어를 기본으로 검토하며, 모터 배치와 내부 구조를 바꿔 저지연을 목표로 합니다. 크기 확대나 손가락만의 축소를 먼저 확정하지 않습니다.

목표는 **로봇 자체의 추종 지연 50ms 이하, 정해진 시험 범위의 최대 지연 100ms 이하**입니다. 로봇 제어부가 목표 각도를 받은 뒤 실제 관절이 따라오는 과정이 대상입니다. 카메라·인식·장갑의 입력 지연은 이번 평가에서 제외합니다. 추종 지연은 90° 회전 전체를 끝내는 시간과 다릅니다.

![수용한 손 모양을 유지한 제작 개선 후보](cad/manufacturing_v1/generated/whole_hand.png)

*왼쪽은 이전 형상, 오른쪽은 제작 개선 후보입니다. 손 비율·길이·관절축을 유지하고, 조립할 때 막히던 원위 핀10개와 부싱10개를 수정했습니다. 엄지는 펼친 위치를 유지한 채 끝마디만 팔목 쪽으로15° 젖힙니다. [현재 제작 검토](cad/manufacturing_v1/README.md) · [수용한 외형 기준](cad/accepted_form_v1/README.md)*

[핀·부싱 변경 확대](cad/manufacturing_v1/generated/pin_assembly.png) · [현재 전체 STEP](cad/manufacturing_v1/generated/hand.step) · [엄지 자세의 이전 동작 GIF](cad/thumb_wrist_v1/generated/motion.gif)

현재는 **실제로 제작하고 조립할 수 있는 CAD**를 만드는 단계입니다. 최종 위치의 겹침뿐 아니라 부품 삽입 경로·공구 접근·조립 순서·공차를 함께 확인합니다. 원위 관절은 원형 자유 회전 핀으로 바꾸었으며, 이후 구동 토크는 움직이는 링크나 풀리에 연결합니다.

**현재 후보 검사 결과:** 저장 CAD349개와 전체 STEP 재수입 대조, 핀10개의 관절 내부 삽입 경로 확보, 최신 엄지 자세를 포함한10개 정적 자세에서 보고 기준 이상 겹침0건·연산 실패0건. 손 전체 조립 후에는5개 핀의 경로를 옆 손가락이 막으므로 손가락 모듈을 먼저 조립하는 순서가 필요합니다. 클립의 탄성 설치·공차·공구 접근·강도와 실제 구동계는 남은 과제입니다. [검사 범위와 결과](cad/manufacturing_v1/README.md)

이전 [엄지 후보의48개 경로 표본](cad/thumb_wrist_v1/README.md), [9개 끝자세](cad/gesture_hand_v3/generated/gestures_oblique.png), GESTURE002의 세 정방향 경로228표본 기록도 보존합니다. 해당 결과를 수정 형상의 모든 동작 검증으로 승계하지 않습니다. GIF 재생시간은 실물 속도가 아니며 실제 모터·줄 구동과100ms 성능은 아직 검증하지 않았습니다.

> CAD와 시뮬레이션을 반복 개선하는 단계입니다. 제작 승인과 실제 하드웨어의 100ms 이하 성능 검증은 아직 완료하지 않았습니다.

## 현재 설계

| 항목 | 개발 방향 |
| --- | --- |
| 손 크기·형태 | 수용한 FORM002의 손바닥180×150mm, 엄지65/50/52.6mm와 네 손가락 비율·관절 배치 유지. [현재 외형 기준](cad/accepted_form_v1/README.md) |
| 손가락 | 20축 독립 제어 기본안. 16축 연동은 별도 비교 옵션 |
| 모터 배치 | 이전 DRIVE001의 실제 크기20개(손바닥6·후면14)를 새 관절 CAD와 다시 대조. 현재 손 조립에 통합 완료된 모터는0개 |
| 전달 구조 | 새 엄지 축·깊은 굽힘 범위에서 원격 줄 구동 경로를 재설계. 실제 관성에 연결한 가정 전달계 계산과 조립된 구동계를 구분 |
| 손목·팔 | 연결 형상을 고려하되 손 단독 성능 평가와 구분. 팔 통합 검증은 후속 과제 |
| 모터·예산 | XL330과 과거 약500만원 예산은 비교 기준이며 고정 제약이 아님 |

모터 수 감소와 소형화가 저지연의 필수조건은 아닙니다. 같은 길이와 표현 자유도에서 원위 질량을 줄이는 효과를 먼저 확인합니다. 줄의 마찰·늘어남·예압과 인접 관절이 움직일 때의 줄 길이 변화도 함께 설계합니다.

이전 재배치 후보는 큰 손바닥과 직선 링크, 엄지 외부 모터 때문에 외형 기준을 충족하지 못했습니다. 해당 CP007은 보존하고, 손바닥 폭·길이를 약22~23% 줄인 새 중공 형상에서 개선을 재개했습니다. 모터 배치·지지 랙과 새20축 동역학을 연결하되, 전체 전달계가 완성되지 않았으므로 이전 후보의 무게·지연 결과를 새 형상의 성능으로 쓰지 않습니다.

## 성능 확인 방법

입력 장치 없이 목표 관절각을 재생해 작은 왕복, 빠른 굽힘·펴기, 급반전, 여러 관절의 동시 움직임을 비교합니다.

- 모든 축·방향의 추종 지연을 집계하고 목표에 도달하지 못한 사례를 누락시키지 않습니다.
- 원래 시간축의 각도 오차, 지연 보정 후 모양 오차, 정착시간·오버슈트를 별도로 기록합니다.
- 작은 동작은 진폭에 비례한 임시 정확도 기준도 확인합니다. 시작부터 임계각을 지난 상태와 실제 미도달을 구분합니다.
- 가운데·끝마디를 독립적으로 움직여 16축 연동 구조의 자세 표현 손실과 동역학 오차를 나눠 비교합니다.
- 현재는 중력·마찰·탄성·예압·질량·축간 경로 계수·내부 통신 조건을 바꾼 민감도를 확인합니다. 풀리 반경 전달비와 모터 속도·토크·출력 상승률의 비교는 다음 과제입니다.
- CAD의 형상·질량·관성과 동역학 입력을 대조하고, 중력·반전·에너지 일관성과 시간간격 수렴을 검사합니다.
- 체크포인트마다 커밋·푸시 후 같은 SHA의 깨끗한 사본에서 핵심 검사를 재실행합니다. [검토 절차](docs/CHECKPOINT_WORKFLOW.md)

시뮬레이션은 명시한 모델과 시험 범위에서만 유효합니다. 실제 서보 제어, 줄 마찰, 열, 조립 공차를 실측하기 전에는 물리 성능 통과로 표시하지 않습니다. 실제 손가락 관절각은 줄을 감는 모터 축의 각도와 구분하여 측정해야 합니다.

이전 CP006과 DRIVE001의 계산은 해당 기록에 남깁니다. 최신 엄지와 주먹 형상은 축·질량·관절 범위가 달라 새 모델로 다시 평가합니다. 전체 가동 범위·줄 감김·체결·강성·실제 구동계 보정은 남아 있습니다. **100ms 목표 달성을 주장하지 않습니다.**

## 다음 개발 과제

수용한 손 비율과 팔목 쪽으로 끝마디를 젖힌 엄지 자세를 유지하면서 실제 제작·조립·구동이 가능한 CAD로 개선합니다. 완성 위치의 겹침뿐 아니라 부품을 끼우는 경로, 공구 접근, 조립 순서와 공차를 확인합니다. 아래 과제는 단계별로 수정·검사·저장하며, 실제 구동계가 들어가기 전에는 속도 통과를 주장하지 않습니다.

| 과제 | 확인할 내용 |
| --- | --- |
| 외형과 내부 배치 | 새 관절과 겹치는 기존 손바닥 모터를 손목·전완으로 옮길지 비교하고, 고정·정비 접근·후면 돌출을 함께 검토 |
| 전달 구조 | 풀리·스풀 반경, 양쪽 줄 고정·예압 조절, 동시 관절 운동의 보상 속도 |
| 모터 성능 | 부하가 있는 속도·토크, 급반전, 출력 상승, 전류·열·전원 여유 |
| CAD·조립 | 새 관절·모터 고정부의 지지, 전 가동 범위 간섭, 체결·공구 접근과 강도 |
| 자세 표현 | 20축 유지안과 16축 연동안의 대표 자세 오차 |
| 실물 시험 | 손가락 하나의 실제 관절각·장력·전류·지연 측정 후 전체 손으로 확장 |
| 손목·팔 | 손의 변경된 질량·관성으로 구동계와 통합 추종 재평가 |
