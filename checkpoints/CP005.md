# CP005 — 실제 연결축·모터 배치와 자세 평가 보완

## 변경

CP004 `ad62a517b4fdd19bc434448ccb4da079ddfcc37c`를 커밋·푸시하고 깨끗한 사본의 재현 결과를 `89c37ed`에 남긴 뒤 두 번째 회차를 진행했다. 기존 보존 브랜치와 V9 동결 자료는 그대로다.

CAD는 원래 손바닥·뿌리·마디 길이·20축을 유지한다. 엄지 MCP 부모 포크를 기존 자식 축과 같은35°방향으로 돌리고 짧아진 쉘을 어댑터로 연결했다. 다섯 손가락 모두 원래 H101 혼 체결면(Y17~22mm)을 남기고 뒤쪽 불필요한 스텁을 줄였으며, 보존한 출력 나사의 실제 형상으로 새 브리지의 간섭 부위를 비웠다. 엄지 브리지만 추가로22→20mm 좁혔다. 손바닥 모터 배치의 위치·높이·방향을 조정하고 엄지 모터의 아래쪽 받침대를 수정했다. 새 손바닥 고정판은 실제 섀시 연결 지지대·체결이 아직 필요하다.

정확한 솔리드 검사에서 중립 자세 겹침 목록은33→0개, 실제 원통면을 이용한 부모 보어·자식 보어·핀의 축 검사는10개 원위 관절에서 일치했다. 이는 선택한 중립 자세와 명목 축의 검사이며 조립·연속 동작 통과가 아니다. 형상223개는 모두 BRep 유효성 검사를 통과했다.

전체 손 밀도 기반 질량은1.446564→1.440938kg, 중지 이동 부분은55.790→55.031g이다. 전체 실체 경계는 X[-116.000,134.895], Y[-81.000,326.000], Z[-71.000,30.000]mm다. CP004보다 +X방향으로6.813mm 돌출이 늘었고 Y/Z는 같다. 이는 외형이 완전히 같다는 주장을 대신하는 실제 경계 비교다.

고정판의 간섭 부위를 비우는 과정에서 생긴 분리 조각 2.963455mm³도 검토에서 찾아 제거했다. 새 제작 부품 56개는 각각 하나의 연결된 솔리드인지 검사한다. 조립 경계는 삼각형 표시망 대신 정확한 곡면으로 계산한다.

생성기는 소스·설계·원본 입력의 실행 전후 해시를 비교한다. 형상 내 관절축 자가 검사와 저장 STEP을 다시 읽는 검토도 구분했다.

## 평가 수정과 검사

작은 동작의 임계각을 시작부터 지나 있었던 경우와 구간 내 끝내 도달하지 못한 경우를 분리했다. 두 경우 모두 시차를 확정하지 못하므로 기존 누락 집계와 보수적인 사건 예산 판정을 유지한다. 이른 통과의-10ms 기준은 임시 위상 품질 기준이며 사용자 요구에서 나온 지연 하한이 아니다.

기존3° 정착 기준을 유지하되, 추가 정착 검사에는 `max(0.1°,min(3°,구간 진폭×0.1))` 각도 띠를 적용한다. 움직이지 않는 축도 검사한다. 이는 임시 평가 기준이며 실물 센서 정밀도·승인된 정확도 사양이 아니다. 작은5° 동작도125µs/62.5µs 간격에서 비교해 최대 차이≤0.02° 및80개 정착 상태의 일치를 검사했다. 실제 최대 차이는 약0.01885°로 기준에 가깝다. 이는 해당 명목 작은 동작의 확인이며 모든 동작·민감도의0.1°정착 판정까지 검증한 것은 아니다. 급반전의 최대 간격 차이는 약1.1752°다. 정확한 결과는 [일관성 결과](../sim/remote_drive_v1/results/model_consistency.json)에 남긴다.

독립 PIP/DIP 동작을 추가해20축과16축에 같은 요청을 준다.16축의 연동 가능한 목표를 따로 만들고 요청→목표의 표현 손실, 목표→응답의 동역학 오차, 요청→응답의 전체 오차를 나눴다. 이 시험에서 가상16축의 명령 투영 손실은 최대60°다. 기존6개 동작은 이미 DIP=0.8×PIP 관계여서 이 손실을 검사하지 못했다.

끝점 초과와 반전 시 이전 방향으로 더 움직인 각도를 따로 기록한다. 기본21개 시험의 요청·목표·응답을 모두 표시용 궤적으로 저장했고,29개 계산 모두 전체 해상도로 명령을 재구성할 구간 정의를 남겼다. 비교 화면에는7개 동작 선택과 세 가지 각도 표시를 추가했다.

모델 검사12개를 통과했다. 동역학은21개 기본 시험과8개 민감도다. CP004의 기존 직결6개 동작에 대해서는 이전 지표와 사건·정착·축별 수치가 그대로 유지됨을 별도로 대조했다. 제어 이득·모터 사양 가정·기본125µs 시간간격은 변경하지 않았다.
