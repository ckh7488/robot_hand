# CP003 — README 소개와 문서 흐름 정리

- 날짜: 2026-10-24 KST
- 범위: 문서 정리. 설계 후보는 CP002의 V13을 그대로 유지합니다.

## 변경

- README 제목과 첫 문단을 프로젝트 소개로 바꾸고, 첫 이미지를 기존 V9 손·전완 전체 배치로 교체했습니다.
- 프로젝트 구성, CAD 파일 안내, 저장소 구조, 검토 방법, 다음 개발 과제를 순서대로 정리했습니다.
- V9~V13 개정 이력과 CP001·CP002 상세 기록, 진행 요약 링크를 하단에 모았습니다.
- V9 전체 조립과 V12·V13 손 조립의 차이, CAD 계산 질량과 실측의 차이를 명시했습니다.
- 최대 주먹 간격 0.665 mm, 팔 구동계 부족, 미완성 전체 배선, 제한된 V9 자세 검사의 범위와 미검증 성능은 그대로 남겼습니다.

기존 CP002 manifest는 README도 해시로 고정하므로 수정하지 않습니다. 문서가 바뀐 현재 스냅샷을 CP003 manifest로 추가하고 CHECKPOINT.json의 참조만 전환합니다. CAD, 이미지 원본, 검사 코드, 기존 manifest와 동결 감사 자료는 변경하지 않습니다.

## 확인 범위

커밋 전에 README의 상대 경로·목차 링크, 변경 범위, V9 동결 자료와 기본 읽기 전용 검사를 확인합니다. 커밋 후 해당 SHA의 별도 깨끗한 사본에서 다음을 다시 확인하고 docs/reviews에 결과를 남깁니다.

- README의 파일·이미지·목차 링크와 소개/개정 이력의 순서.
- `verify_audit_evidence.py --full`, `kinematics_numpy.py`, `tools/check_checkpoint.py`, `tools/test_offline_pose_guard.py`.
- 문서와 관리 기록 외의 파일이 이전 커밋과 동일한지, 검토 사본이 검사 후에도 깨끗한지.

FreeCAD 정밀 형상과 전체 경로는 이번 문서 수정으로 재계산하지 않습니다. 해당 결과의 근거는 [CP002 커밋 후 재검토](../docs/reviews/CP002_f4739db.md)이며, 이번 검토를 새 CAD 승인이나 독립 감사로 표현하지 않습니다.
