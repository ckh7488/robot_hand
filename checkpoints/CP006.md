# CP006 — 실제 모터 체결과 엄지 급반전 진단

CP005 `25ba8cd01c07ff9b0efdf65212911e6e629b3270`와 커밋 후 재현 기록 `a97a0a0`에서 이어진 회차다. 기존 직결 보존 브랜치와 V9 증거는 그대로다.

## 실제 CAD 변경

손바닥 원격 모터 8개에 기존 공급사 S101 브래킷, 몸체 나사 4개씩, 베이스 나사·너트 4쌍씩과 두께2.8mm 어댑터를 배치했다. 모터의 X방향 몸체 체결과 브래킷 아래쪽의 체결을 구분한다. 어댑터의 중지 PIP 부분은 기존 엄지 뿌리 모터에 맞춰 국소 절개했다. 모터 위치·손가락 길이·뿌리·20축·풀리 반경은 그대로다.

**완료 범위는 모터→브래킷→어댑터다. 어댑터→차체 연결은8개 모두 없고, 완성된 차체 하중 전달 경로는0개다.** 동역학에서 이 부품들을 손바닥에 고정했다고 가정하는 것과 실제 기구 지지의 완성은 구분한다. 움직이는 엄지 모터 두 개의 체결도 이번 수정 범위 밖이다.

전체 가정 질량은1.440938→1.472997kg으로 약32.059g 늘었다. 추가 질량은 손바닥 고정 몸체에만 반영되며, 움직이는20개 몸체의 질량·무게중심·관성 및 관절 정보는 CP005와 정확히 같다. 실제 실체 외접 크기는250.895×407×101mm로 유지했다. 손목·팔에 걸리는 전체 손의 하중은 후속 평가 대상이다.

## 동역학과 진단

정상 동작의 모터 조건·제어 이득·반경을 바꾸지 않았다. 모델 검사16개가 통과했고, 기존21개 동작과8개 민감도의 모든 지표는 CP005와 정확히 같다. 이번 체결부 추가가 손가락 추종 성능을 향상시켰다고 주장하지 않는다. [기본 보고서](../sim/remote_drive_v1/results/report.json), [회귀 대조](../sim/remote_drive_v1/results/cp005_nominal_regression.json).

추가6개 계산은 엄지 대립축의 원인 분리용이다. 해당 축만 이상화한 조건에서도 다른 구동축은 원래 모형을 유지한다. 엄지 단독 시험은 다른 관절에 정지 명령을 주며, 그 몸체를 제거하거나 물리적으로 잠그는 시험이 아니다. 아래 수치는 원래 시간축의 엄지 최대 각도 오차이며 지연 또는 제작 통과율이 아니다.

## 정지 유지 토크의 추가 확인

엄지 단독 요청 범위10자세, 전체 손의 요청10자세, 엄지 단독 선언 관절 범위25자세를 검사했다. 다른 모든 관절을 가상 외력으로 유지한 정지 자세이며 실제 PD·줄 장력 평형을 푼 결과가 아니다. 엄지 대립은 이 모형에서 직접 구동이며, 다른 모터는 이 축에 직접 구동 토크를 공급하지 않는다.

표본 최대 중력 토크는0.036873N·m, 기존 모델의 정지 출력 상한 가정은0.102381N·m다.45개 표본 모두 이 상한 안에 있다. 위치 에너지의 수치 미분과 중력 토크는 최대6.1e-11N·m 이내로 일치한다. **이 표본에서는 단순한 정지 유지 토크 부족을 뒷받침하지 않는다.** 가속·속도·피드백·제동 중의 여유, 실물 연속 정격과 실제50/100ms 성능은 별개다. ## 표시·다음 작업

동작 비교 화면은 보고서의 설계·모델 입력 해시를 대조한다. 서로 다른 급반전 별칭 궤적이나 다른 CAD 버전의 보고서가 섞이면 생성에 실패하도록 바꾸고, 복사한 CP005 입력의 정상·잘못된 별칭·변경된 설계 세 조건으로 확인했다. 화면은 여전히 관절 중심 표시이며 실제 CAD 충돌 재생이 아니다.

다음은8개 어댑터의 실제 차체 지지, 엄지 모터 체결, 실제 줄 경로·장력 조절이다. 동역학은 정지 중력량을 넘어선 가속/속도·출력 제한·피드백의 상호작용을 분리하고, 필요한 실물 응답 계측을 구체화한다. 현재100ms 목표 달성·제작 승인은 없다. 커밋 뒤 같은 SHA의 깨끗한 사본에서 저장 STEP·샘플 자세·16검사·29계산·6진단·45자세를 다시 실행한다.
