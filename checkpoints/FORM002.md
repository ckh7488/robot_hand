# FORM002 — 수용한 손 비율과 작성 주먹 인계

- 기준: `cad/accepted_form_v1`의 손바닥180×150 mm, 엄지65/50/52.6033 mm, 네 손가락 치수와20축 프레임. 상대 경로124메시와33개 작성 자세를 함께 보존했다.
- 이미지: `cad/accepted_form_v1/images/accepted_fist.gif`, `accepted_fist_frames.png`. 실제 웹캠 품질은 수용되지 않았다.
- 검사: `cad/accepted_form_v1/verify.py`로 입력 해시·상대 경로·관절 범위·수치 기구학/렌더 일치를 확인한다. 결과는 `docs/reviews/FORM002`에 기록한다.
- 미해결: 메시를 변형한 외형 참고이므로 제작 CAD 재구성, 충돌·체결·구동 검사는 CAD 전용 작업에서 이어간다. 본 회차는 그것을 수행하지 않았다. 인식의 비물리적 좌표 변화와 변환 증폭/재인식 점프는 별도 코드 수정 대상이다.
