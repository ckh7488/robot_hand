# DRIVE001 — 다듬은 손 외형에서 구동 개선 재개

손바닥180×150mm·중지154mm와 새 엄지 형상을 유지하면서 저관성 구동을 다시 연결했다. 원본 `form_candidate_v1`과 동결 V9 자료를 수정하지 않고 `cad/form_drive_v1`, `sim/form_drive_v1`에 만들었다. 미완성 CP007과 외부 축소 연구는 별도로 보존한다.

## 실제 변경

- 실제 크기의 M077 공급사 모터20개, 새 받침·후면 랙·스풀 공간을 모델링했다. 손바닥6개와 전완 랙14개이며 그중4개는 손목 뒤 구역에 놓는다. 장착 하중 경로와 모터축·줄 연결은 미완성이다.
- 외형120부품의 BRep 체적·COM·전체 관성텐서를 산출하고21개 강체에 집계했다. 가정 밀도에서 외형0.656kg, 움직이는 부분0.290kg이며 완성 조립 무게가 아니다.
- 새20축 좌표에 정확06b9ab4의 힘 계산·평가 함수만 연결했다. 모터·줄·제어 특성은 미실측 가정이며 모든축의 실제 줄 경로를 완성한 것은 아니다.
- 중지 PIP/DIP의 양방향 끝단 길이와8mm 풀리 접선·원호를85자세에서 검사했다. 실제 전완 스풀→외피 입구, 외피 길이 보존·압축·간섭이 빠져 전체 전달행렬은 미확정이다.

## 검사 결과와 판정

어댑터의13개 검사는 실제 질량 계약까지 확인했다. 형상과 동역학 연결의 일관성 검사이며 성능 통과가 아니다. [배치 검사](../cad/form_drive_v1/generated/packaging/geometry.json)는 중립 자세의 새 부품 체적 겹침만 대상으로 한다. 초기 스풀 충돌4쌍을 찾아 모듈 방향·위치를 수정했으며, 최종247쌍의 정밀 Boolean 검사에서 남는 겹침0·계산 실패0을 확인했다. 새 제작 부품97개는 모두 유효 단일 솔리드다. 초기 실패는 배치 이력에 보존한다. 공차·변형·전체 가동 범위·조립성 검증은 아니다.

[전체 손 선별 계산17건](../sim/form_drive_v1/results/drive001/summary.json)은 입력 변경 없이 완료됐다. 합산 경로 가정의 빠른90° 시험은 유효 사건 최대139.6ms, 누락6건, 최대오차56.36°였다. 경로계수를 줄인 가정도 전체 성능이 좋아지지 않았다. 모터 요구속도가 줄어도 앞마디를 지원하던 토크가 줄어들기 때문이다.

**수렴6쌍 중1쌍만 기준을 충족해 지연·최적점은 미확정**이다. 작은 동작·급반전·정착 실패를 그대로 저장했다. `100ms 이하 달성`, 제작 승인, 팔 통합 통과로 표시하지 않는다. 숫자의 범위와 해석은 [새 모델 설명](../sim/form_drive_v1/README.md)에 있다.

## 다음 회차

1. 두 경로 가정의 중지 MCP 빠른 동작에서 모터 요구 토크·실제 제한 토크·줄 전달 토크를 기록해 출력 부족과 반전 제어를 분리한다. 시간 간격을 더 줄여 수렴을 먼저 확보한다.
2. 작은5° 동작에서 모터각 오차와 줄 변형·관절 오프셋을 분리한다. 도달 판정을 느슨하게 바꾸지 않는다.
3. 실제 스풀부터 중지의 외피 종단까지 연결하고 손목 통과·예압·최소 굽힘 반경·체결과 움직이는 전달 부품 질량을 반영한다. 후면 랙의 돌출을 줄이는 배치도 비교한다.

자동 반복은 사용자 재개 지시에 따라30분 간격으로 활성화했다. 매 회차 실제 변경·근거·미해결 항목을 커밋·푸시하고 해당SHA의 깨끗한 사본에서 핵심 검사를 재실행한다. 이번 후속 재검토 기록도 대상SHA를 명시해 별도로 남긴다.
