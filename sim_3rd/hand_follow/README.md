# hand_follow — 웹캠으로 실제 CAD 손 따라 하기

`D:\robot_hand\cad\form_candidate_v1`의 실제 STL 120개를 20개 관절에 연결한다. 웹캠과 CAD를 한 창에 표시하며, 손 인식 → 관절 변환 → 보정 → 필터 → 범위 제한 → 화면 적용을 각각 기록한다. 손목의 위치·회전은 고정하고 손가락 관절을 따라 한다.

## 실행

이 PC에서는 `start_webcam.pyw`를 더블클릭한다. 콘솔 창 없이 실행하며 오류는 D: 작업 폴더에 남긴다. Python 3.12와 전용 패키지를 사용한다.

별도 환경 설치:

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python follow_sim.py --repo D:\robot_hand
```

- 기본 카메라 요청은 640×480, 30fps다. 화면의 카메라 fps는 실제 수신율이며 30fps를 보장하지 않는다.
- `--source 1`: 다른 카메라. `--source synthetic`: 카메라 없이 합성 동작 확인.
- `--whole`: CAD에 포함된 참고용 전완까지 표시.
- `--no-gui --seconds 8`: 화면 없이 제한 시간 실행.
- `--log-dir`: 수치 로그 위치. `--calibration`: 보정 파일 위치.
- 실행기는 `HAND_FOLLOW_WORK`, `HAND_FOLLOW_DEPS` 환경변수로 작업 폴더와 패키지 위치를 바꿀 수 있다.

## 사용

창을 클릭한 뒤 키를 누르거나 화면 버튼을 누른다.

| 키 | 동작 |
|---|---|
| C | 손가락을 붙여 편 손을 약2초 유지. 여러 프레임의 중앙값으로 영점 보정 |
| V | C 이후 주먹을 약2초 유지. 네 손가락의 굽힘 범위를 개인 손에 맞게 보정 |
| X | 개인 보정 초기화 |
| T | CAD 자체의 주먹 자세 확인. 화면에 테스트 모드가 표시되며 다시 누르면 추종 재개 |
| 1 / 2 / 3 | 정면 / 사선 / 측면 |
| H | 추적할 손 다시 선택 |
| F | 떨림 필터 켜기·끄기 |
| D | 검지의 인식각·보정각·적용각과 관절 제한 개수 표시 |
| Q / Esc | 종료. 창 닫기 버튼도 종료 |

보정 없이도 동작한다. 손 크기·자세·인식 깊이 때문에 주먹이 덜 닫히면 C와 V로 범위를 보정한다. 최근1.4초 관절값의 중앙값과 중앙 절대편차로 흔들림을 검사한다. 뿌리·가운데마디 변화가15도 미만이면 주먹 보정을 거부하고, 이득은 최대4배로 제한한다. 끝마디만 가려져 변화가 부족하면 해당 끝마디에만 가운데마디의 굽힘 비율을 사용한다. 이 경우 화면과 로그에 `끝마디 추정`을 표시하며, 그 마디의 독립 추종은 할 수 없다. X로 초기화하면 해제된다. 보정은 `calibration_v3.json`에 저장하며 이전 파일은 보존한다. V는 네 손가락의 범위를 보정하고, 엄지는 관절점 위치로 별도 계산한다.

## 이전 구현에서 바꾼 것

- 막대형 모델을 실제 CAD로 교체했다. 조립된 세계 좌표의 STL을 각 관절의 중립 좌표로 변환한다. 원본 형상·부품 색·부품 간 위치를 유지하며 CAD 파일을 수정하지 않는다.
- 깊은 굽힘에서 투영 방향이 뒤집히는 오류를 수정했다. 기존 코드는 뿌리95° / 가운데90° / 끝65°를 뿌리85° / 가운데−90° / 끝−65°로 바꾸고, 음수를0°로 제한했다. 새 계산은95° /90° /65°를 유지한 뒤 로봇 표시 범위를 적용한다.
- 엄지는 최신 CAD의 기본 회전−40°와 두 번째 관절의25° 방향 전환을 반영한다.
- 사람 엄지의 비틀림을 고정된 CAD 축에 투영하면 주먹에서도 거의0도로 나오는 문제가 있었다. 엄지 중간점·끝점의 위치를 따르는 제한 범위 내 역기구학으로 바꿨다. 주먹을 가로지르는 엄지가 관측되면 검지와의 상대 위치를 사용하고, 접힌 손가락 외측으로 목표 높이를 보정한다. 주먹 여부만 보고 정해진 엄지 자세를 재생하지 않는다.
- 깊게 접힌 손가락에서 불안정한 벌림값을 중립 방향으로 완화한다. 가운데·끝마디 굽힘은 각각 독립적으로 전달한다.
- 손 선택에 위치 연속성과 좌우 판정 유지 시간을 적용했다. 손이 사라지면 마지막 자세를 유지하고 화면에 표시한다.
- One Euro 필터의 속도 추정을 직전 원시 입력 기준으로 수정했다.
- 카메라의 첫 프레임은 최대15초 기다린다. 실행 중 영상이4초 끊기면 종료하고 오류를 기록한다.

## 로그

기본 위치: `D:\Codex-work\robot-hand-workspace\work\hand_follow_sessions`.

`latest_session.json`에서 현재 세션 폴더를 찾는다.

- `session.json`: 카메라·필터 설정과 사용한 CAD/메시 SHA256.
- `angles.csv`: 프레임별 인식각, 보정각, 명령각, 실제 화면 모델 각도. 마지막 값은 실물 센서값이 아니다.
- `landmarks.jsonl`: 최대10Hz의21개 관절점, 변환 단계 값, 관절 제한 목록, 처리 시간. `thumb_fit`에는 엄지 목표 위치·목표 오차·주먹 외측 보정 가중치가 남는다.
- `events.jsonl`: 보정 요청·결과, 테스트 모드, 종료·오류.
- `status.json`: 처리 프레임 수, 손 검출 수, 실제 카메라 수신율, 최근 실행 상태.

카메라 사진·동영상은 저장하지 않는다. 테스트 모드는 로그에 `mode=test`로 구분한다. 입력→각도 시간에는 카메라 노출·USB 수신 이전 지연과 화면 표시 지연이 포함되지 않는다.

## 검증과 범위

```powershell
python -m unittest discover -s tests -v
```

검사는 원본 CAD 중립 메시 위치,20축 이름 연결, 다른 손가락의 독립성, 주먹 끝점 이동,90° 전후의 굽힘, 실제 MediaPipe 공식 사진에서 추출한 관절점, 좌우손·카메라 회전, 보정·추적 소실·필터를 다룬다. 공식 샘플의 원본/좌우 반전 좌표는 `tests/data/mediapipe_poses.json`에 출처와 함께 보존한다. 합성 손의 왕복 검사만으로 실제 웹캠 품질을 판정하지 않는다.

이 화면은 자세 미리보기다. 관절 범위는 기존20축 명령 제한을 계승한 표시 범위이며, 새 외형 CAD의 전체 가동 간섭·모터·줄·실물 성능을 검증하지 않는다. 엄지 외측 보정은 CAD 두께를 근사한 위치 보정이며 실제 메시 충돌 검사나 물리 접촉 해석이 아니다. 사람 엄지와 CAD 엄지의 축·비율 차이로 도달하지 못하는 위치는 남으며, 목표 오차25mm 초과를 화면에 표시한다. 가려진 마디의 깊이 추정 오차도 남는다. 보정 후에도 특정 자세가 맞지 않으면 수치 로그로 인식과 변환 문제를 분리한다.

`replay_in_sim.py`는 기존 `sim/remote_drive_v1` 동역학용 연구 도구로 남겨 둔다. 새 외형 CAD의 성능 평가 도구가 아니며, 그 결과를 현재 화면 모델의 실제 성능으로 해석하면 안 된다. 최신 외형과 구동 설계 작업은 별도 프로젝트 경로를 따른다.
