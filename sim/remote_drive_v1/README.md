# 로봇 단독 전체 손 동역학 — 첫 비교 모형

다섯 손가락의 20개 관절을 한 MuJoCo 강체 모델에서 동시에 계산한다. 원격 구동안은 케이블용 모터 10개의 출력축 좌표를 추가해 모터 인코더 각도와 실제 관절각을 구분한다. 결과는 **선언한 가정에 대한 수치 실험**이며, 50ms 목표 또는 100ms 상한의 실물 달성을 뜻하지 않는다.

## 입력과 비교 경계

- `baseline20`: 동결된 V9 관절 위치·길이·부품별 질량·무게중심. 부품 자체 관성은 경계 상자 근사이며 평행축 정리로 합친다. 과거 CAD의 재료 밀도와 제조사 프레임 질량은 실측값이 아니다.
- `remote20`: `cad/remote_drive_v1/simulation_contract.json`의 실제 CAD 솔리드에서 산출한 질량·무게중심·관성 텐서를 사용한다. 계약 파일이 없거나 불완전하면 실행을 중단한다. 엄지 모터 두 개의 질량은 움직이는 받침대에 포함된다.
- `remote16`: 같은 20모터 CAD 질량을 유지한 채 네 DIP 구동을 제거하고 `DIP=0.8×PIP`를 구속한 가상 비교이다. 별도 16모터 제작안이 아니다. 세 구조에 같은 요청 자세를 주고, 이 비교에만 연동 관계에 맞춘 실행 가능한 기준 자세를 만든다. 요청과 기준의 차이, 기준과 응답의 차이, 요청과 응답의 차이를 각각 공개한다.
- 입력 시작은 로봇 제어부가 목표 관절각 스트림을 받은 시점이다. 로봇 내부 전송 2ms, 제어 갱신 1ms를 기본 가정으로 포함한다. 카메라·인식·장갑은 없다. 지연이 커지는 사례는 별도로 계산한다.
- 손바닥과 팔 연결은 고정한다. 팔 동역학을 검사하지 않는다. 새로운 CAD 후보의 관절 범위를 두 구조에 동일 적용하지만, 그 범위가 충돌 없이 사용 가능하다는 뜻은 아니다.

## 모터와 전달장치

XL330-M077의 5V 무부하 383rpm, 정지 토크 0.215N·m를 사용한다. 정지 전류 1.47A와 설정 전류 0.7A의 비율로 토크 한도를 근사한다. 제조사 전류는 공급 측 수치이므로 실제 상전류-토크 선형 관계를 검증한 것으로 해석하면 안 된다.

PWM Slope는 `140×1.977mV/ms`의 실제 듀티 변화율로 적분한다. 가상의 8.6ms 고정 지연은 넣지 않는다. 역기전력을 포함한 준정적 전압-토크 식에 전류 한도를 적용한다. 전기적 시정수·열·전원 강하는 아직 없다.

제어기는 모터 축의 위치/속도 오차에 대한 명시적인 PD와 목표각 차분의 속도 전향 항이다. 기본값은 `Kp=1.2N·m/rad`, `Kd=0.012N·m·s/rad`. 실제 XL330 펌웨어 PID/프로파일을 재현하거나 보정한 값은 아니다. 실제 관절 출력의 추가 센서가 있다고 가정하지 않는다.

케이블 모터 목표각은 `θmotor=Aq`이다. 당기는 두 줄의 늘어남, 감쇠, 초기 장력, 느슨해지는 경우와 진행 방향에 따른 마찰을 계산한다. 모터에는 반작용을, 링크에는 동일한 행렬의 전치 `Aᵀ`로 구동 토크를 적용한다. 모터 출력축 관성은 별도 좌표에 남으므로 강체 전달 극한에서는 축 사이에 결합 관성이 생긴다. 모터 몸체의 질량은 CAD에 있으나 모터 내부 회전체와 움직이는 하우징의 자이로 결합은 근사한다.

스풀/풀리 반경 8mm, 초기 장력 1.5N과 명목 경로 계수는 CAD 설계 입력에서 읽는다. 케이블 강성 20,000N/m, 감쇠 2N·s/m, 마찰계수 0.04와 유격 0.005rad는 **측정 전 가정**이다. 경로 행렬은 명목 상수이며 실제 3차원 접선·감김·벌림 축 보상·케이블 접촉을 풀지 않는다.

## 시험과 결과 해석

`run_suite.py`는 5°/10° 왕복, 45°/250ms, 최대 90°/150ms, 상위 관절만 움직이고 원위 자세 유지, 연속 급반전, 원위 두 관절의 독립 이동을 각 구조에 적용한다. 기본 7종×3구조=21회와 원격 20축 급반전의 민감도 8회, 총 29회다. 벌림과 일부 관절은 선언된 범위에 맞춰 더 작은 각도를 사용한다. 중력 방향·마찰·강성·초기 장력·질량·축간 경로 계수·내부 통신 지연을 바꾸는 민감도를 추가한다.

`independent_distal`은 MCP를 20°로 유지하고, PIP만 0→60°, DIP만 0→60°, PIP만 60→0°, DIP만 60→0° 순서로 움직인다. 각 이동은 250ms, 정지는 250ms다. 엄지 MCP/IP도 같은 순서로 움직인다. 이 요청은 20축과 16축에 동일하다. 가상 16축 기준은 네 DIP를 PIP의 0.8배로 바꾸므로 요청 자세 자체를 최대 60° 잃는다. CP004의 기존 6종은 이미 네 DIP가 PIP의 0.8배였기에, 독립성 손실을 검사하지 못했다.

- 각 왕복 구간의 10%·50%·90% 통과 시차를 모두 집계한다. CP004와 비교 가능한 `status`/`lag_ms`/`missing_events`는 그대로 유지한다. 새 `classification`은 `preexisting_level`(구간 시작에 이미 임계각 바깥), `never_reached`(구간 내 통과 없음), `early_crossing`(명령보다 10ms 넘게 빠른 통과), `reached`를 구분한다. 앞의 두 경우는 최초 응답 시차를 정할 수 없으므로 계속 누락으로 집계하고 사건 예산 미달로 남긴다. 이후 재통과 시각을 발견해도 최초 응답으로 대체하지 않는다.
- -10ms 기준은 비교용 임시 위상 품질 기준이며 사용자의 100ms 지연 상한 요구에서 나온 값이 아니다. 각도 편향·진폭·응답 모양도 임계각 통과 시차를 바꾼다. 따라서 통과 시차를 순수한 통신 지연으로 해석하지 않는다.
- 원시 시간축의 최대/평균제곱근 각도 오차와 지연을 사후 정렬한 모양 오차를 분리한다. 작은 지연 수치로 큰 오버슈트를 숨기지 않는다.
- 종전 `settling`은 움직인 축의 3°/10°/s 정착 판정을 비교용으로 남긴다. 추가한 `hold_quality`는 정지 구간이 40ms 이상이면 움직이지 않은 축도 포함한 20축을 검사한다. 허용 각도는 **max(0.1°, min(3°, 이동 진폭×0.1))**이며, 관찰된 정지 구간 끝까지 30ms 이상 유지하고 속도도 10°/s 이하여야 한다. 0.1°는 실제 센서 정밀도나 사용자가 승인한 정확도 사양이 아닌 임시 하한이다.
- `projection_loss_*`는 요청 자세와 연동 가능한 기준 자세의 차이, `dynamic_raw_*`는 응답과 기준의 차이, `task_raw_*`는 응답과 원래 요청의 차이다. 종전 `raw_max_error_deg`도 기준과 응답의 오차로 유지한다. 16축에서 기준 추종이 좋아도 요청한 독립 자세를 재현했다는 뜻은 아니다.
- 각 이동 구간의 진행 방향을 기준으로 명령 끝점을 넘어간 `endpoint_overshoot_deg`와 명령 시작점 반대편으로 움직인 `wrong_way_excursion_deg`를 분리한다. 급반전 후 이전 방향으로 더 움직이는 현상은 뒤의 값에 포함된다. 둘 다 관절 허용 범위 초과량과 다른 값이다.
- 전류/전압 포화 비율, 모터 최고 속도, 최대 줄 장력, 느슨해진 비율, 수치 모델의 유연한 관절 정지 범위 초과량을 기록한다.
- `simulated_100ms_event_budget_met`는 해당 사건 지연 조건만 뜻한다. 정착·각도 정확도·간섭·실물 성능의 종합 합격 표시는 아니다.

처음 250µs 적분 간격은 125µs와의 급반전 비교에서 최대 5.29° 차이가 나 일관성 검사를 통과하지 못했다. 기본 간격을 125µs로 줄였으며, 62.5µs와의 궤적 차이를 다시 검사한다. 이는 제어 성능을 개선하는 튜닝이 아니라 수치 해상도 수정이다.

작은 동작의 0.1° 임시 허용폭에는 급반전 수렴 검사만으로 충분하지 않다. CP005에서 `small5`를 125µs/62.5µs로 각각 계산해, 전체 궤적의 최대 차이 **0.02° 이하**와 모든 `hold_quality` 정착 분류의 일치를 별도로 요구한다. 이 기준은 실행 전에 고정하며, 실패하면 작은 동작 정확도 판정의 수치 신뢰도가 미해결임을 남긴다.

CP005 결과는 `small5` 최대 차이 0.018853°와 80개 정지 판정의 일치로 이 기준을 통과했다. 0.02° 경계에 가깝고, 급반전 최대 차이는 1.1752°다. 따라서 이 검사는 명목 `small5`에 대한 근거이며, 다른 동작과 모든 민감도 조건의 0.1° 판정까지 보증하지 않는다. 정확한 값과 입력 해시는 `results/model_consistency.json`에 있다.

## CP006 엄지 원인 분리 시험

`run_thumb_diagnostics.py`는 전체 손 급반전, 엄지 대립만 이동, 대립만 이동하며 중력 제거, 대립 축 PWM 변화율 제한만 제거, 대립 축의 모터 제한을 우회한 이상 토크, 이상 토크에 관성 기반 감쇠를 적용한 경우의 여섯 가지를 별도로 비교한다. 엄지만 움직이는 다섯 경우에는 대립 이외 관절의 명령을 0°로 유지하며 물리적으로 잠그지 않는다. 다른 서보와 케이블은 그대로 계산한다. 반경·기본 PD 이득·모터 정격·전류·마찰 가정은 명목 시험에서 바꾸지 않는다.

마지막 두 경우는 현실의 모터나 제어기 후보가 아니다. 대립 축에만 PD 요청 토크를 그대로 가하고 모터 점성 손실은 유지하며, 나머지 축은 명목 모터 식을 사용한다. 마지막 경우의 감쇠는 실행 전에 선언한 규칙 `Kd=2×sqrt(Kp×max(M[17,17]))`으로 정한다. 다른 관절을 0°에 둔 대립 0°부터 45°까지 5° 간격의 관성을 기록하며, 다른 가속도를 0으로 제한한 관성과 나머지 좌표가 자유로운 순간 관성을 함께 공개한다. 이는 정지 자세의 단일 축 근사로, 결합된 전체 시스템의 임계 감쇠를 구한 것이 아니다.

추가 계측은 제어기 요청 토크의 P/D 성분, 1ms마다 갱신한 뒤 유지하는 목표각·속도와 PWM 요청, 전압 한도 적용 후 PWM 목표, 변화율 제한 후 PWM, 역기전력을 반영한 전류 제한 전후 토크, 점성 손실 전후의 실제 축 토크를 구분한다. 전류·전압·PWM 변화율 제한의 엄격한 발생 조건을 각각 기록하고, CP005의 종전 포화 판정도 유지한다. 이상 토크 분기의 전압/PWM/전류 계산은 적용되지 않는 가상 비교 신호이므로 해당 축의 `applied_*` 제한 표시는 거짓이다. 토크와 속도의 곱은 기계적 출력이며 음의 일은 전기 에너지 회수의 증거가 아니다.

`results/thumb_diagnostics/report.json`에 여섯 분기의 입력·이득 규칙·제한 정의·축별 결과·소스 해시가 있고, `*_opposition.csv.gz`에는 대립 축의 모든 125µs 표본을 반올림 없이 저장한다. 상태는 각 시각의 적분 전 값이며 해당 행의 토크가 다음 적분 구간에 적용된다. 두 그림과 요약 CSV도 함께 만든다. `--output`으로 저장소 밖의 비교 폴더를 지정할 수 있다.

명목 모델의 힘을 바꾸지 않았는지는 같은 입력의 계측 켜기/끄기 궤적·속도·토크·포화·줄 장력이 완전히 같은지 검사한다. 제한 분류·토크 및 출력의 항등 관계, 이상 분기의 적용 범위, 미리 선언한 감쇠 계산도 검사하여 일관성 시험은 총 16개다. 이 계측과 이상 분기의 수치 결과는 원인을 좁히는 근거이며 실제 손의 50/100ms 통과 판정이 아니다.

CP006의 대립 축 최대 원시 각도 오차는 다음과 같다. 명목 29개 시험 결과는 CP005와 모든 수치가 정확히 같으며, 이번 계측은 제어 성능을 개선한 변경이 아니다.

다른 손가락의 동시 이동을 없애도 큰 오차가 남고, PWM 변화율 제한만 제거해도 해결되지 않는다. 중력이나 모터 제한을 제거한 조건의 큰 차이는 이 모형에서 중력 부하와 구동 한도가 상호작용한다는 근거다. 실제 모터의 고장을 특정하거나 특정 모터 교체·이득 변경으로 해결된다는 뜻은 아니다.

## 재현

Python 3.12 환경에 `requirements.txt`의 패키지를 설치하고 저장소 루트에서 실행한다. 외부 가상환경이나 작업 폴더에 의존성을 설치하며 저장소에 패키지·캐시를 넣지 않는다.

```text
python sim/remote_drive_v1/run_suite.py
python sim/remote_drive_v1/test_model.py
python sim/remote_drive_v1/run_thumb_diagnostics.py
```

`results/report.json`에 입력 해시·정확한 적용 매개변수·축별 결과·누락 사건·민감도가 들어 있다. `summary.csv`와 `tracking_comparison.png`는 검토용 요약이다. 모든 기본 시험의 `{variant}_{case}_trajectory.json`에는 요청각 `requested_deg`, 기준각 `command_deg`, 응답각 `actual_deg`가 100Hz 표시용으로 저장된다. `{variant}_trajectory.json`은 기존 뷰어 호환을 위한 급반전 파일의 사본이다. CP004에는 급반전 표시 궤적만 저장했으며, CP005부터 기본 21회 모두 저장한다.

기본 시험과 민감도 모두 보고서의 `command_generation`에 초기각·각 구간의 시작/끝/정지 시각·요청/기준 양 끝각·최소 저크 보간·물리 적분 간격을 남긴다. 표시용 궤적의 반올림된 100Hz 값 대신 이 정보로 전체 해상도의 명령을 재구성할 수 있다. `*.xml`은 생성한 실행 모델이다.

`test_model.py`는 CAD 좌표·단위·질량/관성, 중력과 위치 에너지의 기울기, 전달 행렬의 가상일, 케이블 스프링 에너지/마찰 손실, PWM 변화율/반전, 시뮬레이션 재설정, 미도달 처리, 시간 간격 수렴을 검사한다. CP005에는 알려진 40ms 왕복 지연, 시작 시 이미 지난 임계각의 재통과, 0.6° 명령에 무응답한 경우의 정확도 실패, 독립 요청과 16축 투영 손실, 끝점 초과와 반전 방향 이탈을 구분하는 합성 시험도 추가한다. 전달 행렬의 대수 검사만으로 전체 적분기의 에너지 정확성을 증명하는 것은 아니다.

형상은 원시 강체 표시 도형으로 보여주며 접촉을 끈 상태다. 케이블이 얽히지 않거나 부품끼리 간섭하지 않는다는 검증, 인쇄물 강도, 배선·열·전원·실물 서보 검증은 별도이다.

CP004의 엄지 MCP 35° 프레임은 목표 운동학 축을 모델링했으나 당시 포크·베어링 조립 형상이 그 축을 구현하지 못했다. CP005에서는 CAD가 그 조립을 수정하고 새 질량·무게중심·관성을 전달한다. 동역학 적분이 조립 간극·간섭이나 제작 가능성을 검증하는 것은 아니다. 이번 회차에는 제어 이득과 모터 성능 가정을 조정하지 않는다.
