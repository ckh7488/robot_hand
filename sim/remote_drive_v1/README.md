# 로봇 단독 전체 손 동역학 — 첫 비교 모형

다섯 손가락의 20개 관절을 한 MuJoCo 강체 모델에서 동시에 계산한다. 원격 구동안은 케이블용 모터 10개의 출력축 좌표를 추가해 모터 인코더 각도와 실제 관절각을 구분한다. 결과는 **선언한 가정에 대한 수치 실험**이며, 50ms 목표 또는 100ms 상한의 실물 달성을 뜻하지 않는다.

## 입력과 비교 경계

- `baseline20`: 동결된 V9 관절 위치·길이·부품별 질량·무게중심. 부품 자체 관성은 경계 상자 근사이며 평행축 정리로 합친다. 과거 CAD의 재료 밀도와 제조사 프레임 질량은 실측값이 아니다.
- `remote20`: `cad/remote_drive_v1/simulation_contract.json`의 실제 CAD 솔리드에서 산출한 질량·무게중심·관성 텐서를 사용한다. 계약 파일이 없거나 불완전하면 실행을 중단한다. 엄지 모터 두 개의 질량은 움직이는 받침대에 포함된다.
- `remote16`: 같은 20모터 CAD 질량을 유지한 채 네 DIP 구동을 제거하고 `DIP=0.8×PIP`를 구속한 가상 비교이다. 별도 16모터 제작안이 아니며 목표 자세도 그 연동 관계로 바뀐다.
- 입력 시작은 로봇 제어부가 목표 관절각 스트림을 받은 시점이다. 로봇 내부 전송 2ms, 제어 갱신 1ms를 기본 가정으로 포함한다. 카메라·인식·장갑은 없다. 지연이 커지는 사례는 별도로 계산한다.
- 손바닥과 팔 연결은 고정한다. 팔 동역학을 검사하지 않는다. 새로운 CAD 후보의 관절 범위를 두 구조에 동일 적용하지만, 그 범위가 충돌 없이 사용 가능하다는 뜻은 아니다.

## 모터와 전달장치

XL330-M077의 5V 무부하 383rpm, 정지 토크 0.215N·m를 사용한다. 정지 전류 1.47A와 설정 전류 0.7A의 비율로 토크 한도를 근사한다. 제조사 전류는 공급 측 수치이므로 실제 상전류-토크 선형 관계를 검증한 것으로 해석하면 안 된다.

PWM Slope는 `140×1.977mV/ms`의 실제 듀티 변화율로 적분한다. 가상의 8.6ms 고정 지연은 넣지 않는다. 역기전력을 포함한 준정적 전압-토크 식에 전류 한도를 적용한다. 전기적 시정수·열·전원 강하는 아직 없다.

제어기는 모터 축의 위치/속도 오차에 대한 명시적인 PD와 목표각 차분의 속도 전향 항이다. 기본값은 `Kp=1.2N·m/rad`, `Kd=0.012N·m·s/rad`. 실제 XL330 펌웨어 PID/프로파일을 재현하거나 보정한 값은 아니다. 실제 관절 출력의 추가 센서가 있다고 가정하지 않는다.

케이블 모터 목표각은 `θmotor=Aq`이다. 당기는 두 줄의 늘어남, 감쇠, 초기 장력, 느슨해지는 경우와 진행 방향에 따른 마찰을 계산한다. 모터에는 반작용을, 링크에는 동일한 행렬의 전치 `Aᵀ`로 구동 토크를 적용한다. 모터 출력축 관성은 별도 좌표에 남으므로 강체 전달 극한에서는 축 사이에 결합 관성이 생긴다. 모터 몸체의 질량은 CAD에 있으나 모터 내부 회전체와 움직이는 하우징의 자이로 결합은 근사한다.

스풀/풀리 반경 8mm, 초기 장력 1.5N과 명목 경로 계수는 CAD 설계 입력에서 읽는다. 케이블 강성 20,000N/m, 감쇠 2N·s/m, 마찰계수 0.04와 유격 0.005rad는 **측정 전 가정**이다. 경로 행렬은 명목 상수이며 실제 3차원 접선·감김·벌림 축 보상·케이블 접촉을 풀지 않는다.

## 시험과 결과 해석

`run_suite.py`는 5°/10° 왕복, 45°/250ms, 최대 90°/150ms, 상위 관절만 움직이고 원위 자세 유지, 연속 급반전을 각 구조에 적용한다. 벌림과 일부 관절은 선언된 범위에 맞춰 더 작은 각도를 사용하며, 실제 명령값은 궤적 JSON에 남긴다. 중력 방향·마찰·강성·초기 장력·질량·축간 경로 계수·내부 통신 지연을 바꾸는 민감도를 추가한다.

- 각 왕복 구간의 10%·50%·90% 통과 시차를 모두 집계한다. 이미 임계각을 지나 있었거나 목표를 통과하지 못한 사건은 미도달로 남긴다. 미도달이 있으면 상한을 유한한 수로 표시하지 않고 사건 예산 미달로 판정한다.
- 원시 시간축의 최대/평균제곱근 각도 오차와 지연을 사후 정렬한 모양 오차를 분리한다. 작은 지연 수치로 큰 오버슈트를 숨기지 않는다.
- 명령 정지 후 3° 이내·10°/s 이내로 들어와 관찰된 정지 구간 끝까지 유지하고, 그 유지 시간이 최소 30ms인 정착 여부를 따로 보고한다. 이 허용치는 비교를 위한 임시 기준이다.
- 전류/전압 포화 비율, 모터 최고 속도, 최대 줄 장력, 느슨해진 비율, 수치 모델의 유연한 관절 정지 범위 초과량을 기록한다.
- `simulated_100ms_event_budget_met`는 해당 사건 지연 조건만 뜻한다. 정착·각도 정확도·간섭·실물 성능의 종합 합격 표시는 아니다.

처음 250µs 적분 간격은 125µs와의 급반전 비교에서 최대 5.29° 차이가 나 일관성 검사를 통과하지 못했다. 기본 간격을 125µs로 줄였으며, 62.5µs와의 궤적 차이를 다시 검사한다. 이는 제어 성능을 개선하는 튜닝이 아니라 수치 해상도 수정이다.

## 재현

Python 3.12 환경에 `requirements.txt`의 패키지를 설치하고 저장소 루트에서 실행한다. 외부 가상환경이나 작업 폴더에 의존성을 설치하며 저장소에 패키지·캐시를 넣지 않는다.

```text
python sim/remote_drive_v1/run_suite.py
python sim/remote_drive_v1/test_model.py
```

`results/report.json`에 입력 해시·정확한 적용 매개변수·축별 결과·누락 사건·민감도가 들어 있다. `summary.csv`와 `tracking_comparison.png`는 검토용 요약이다. `*_trajectory.json`은 100Hz로 줄인 표시용 궤적이며 물리 적분 간격과 다르다. `*.xml`은 생성한 실행 모델이다.

`test_model.py`는 CAD 좌표·단위·질량/관성, 중력과 위치 에너지의 기울기, 전달 행렬의 가상일, 케이블 스프링 에너지/마찰 손실, PWM 변화율/반전, 시뮬레이션 재설정, 미도달 처리, 시간 간격 수렴을 검사한다. 전달 행렬의 대수 검사만으로 전체 적분기의 에너지 정확성을 증명하는 것은 아니다.

형상은 원시 강체 표시 도형으로 보여주며 접촉을 끈 상태다. 케이블이 얽히지 않거나 부품끼리 간섭하지 않는다는 검증, 인쇄물 강도, 배선·열·전원·실물 서보 검증은 별도이다.

CP004의 엄지 MCP 35° 프레임은 목표 운동학 축을 모델링한다. 현재 후보의 포크·베어링 조립 형상은 그 회전축 구현을 아직 충족하지 못하므로, 이 동역학 결과로 해당 엄지 조립이 가능하다고 판단할 수 없다.
