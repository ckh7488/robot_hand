# 시험대 제작품과 규격 부품 범위

분리형 엄지 IP 시험대 후보의 부품 준비표다. 소재·치수공차·토크가 미확정이므로 **발주용 승인 도면은 아니다.** 형상은 `generated/scene.json`에 기록한 해시의 STEP가 기준이며, 모든 좌표는 엄지 IP축 원점의 mm다. Z 위쪽이 관절이고 공통판 위는 Z−28, 아래는−36이다. 원래 손 부품이나 모터를 축소·재가공하는 지시가 아니다.

이 표는 **추가48개 체결물**만 집계한다. 원래 엄지 시험편30부품과 모터33부품 내부의 체결물은 장면 목록에 별도로 남아 있다. 추가61부품을 포함해 장면은124부품 행이다. 모터 한 행의 복합 형상은 구매품 한 개와 CAD 솔리드 개수를 구분한다. 제조사 중앙 혼 고정나사는 아직 확인되지 않았고 이 목록에도 완료품으로 포함하지 않았다.

## 좌표와 가공 확인

공통판의 모터 구멍 중심은 X−50/8, Y−156/−99의 네 조합이다. 바닥발은 X−58/34, Y−140/4의 네 조합이다. 부모 받침의 발 구멍은 X±30, Y−33.0488601847542/−17.6585233025497의 네 조합이다. 받침발 슬롯의 X 조절량은 중심에서±0.6이다. 조절할 수 있다는 것이 작동 중 움직여도 된다는 뜻은 아니다.

이 좌표는 CAD 기준을 설명하는 값이며 소수점 자릿수가 가공 공차를 지정하지 않는다. 앞뒤 보강 띠는 원래 손 부품의 실제 면에서 추출했으므로 원본 부품 출력·가공 후 좌표와 접촉을 확인해야 한다. 재료, 기준면, 끼워맞춤·평탄도, 모서리 처리, 나사 조임 토크와 풀림 방지는 제작 검토에서 확정할 항목이다.

규격 근거 원본은 [source_docs](source_docs/README.md), 실제 조립 순서는 [ASSEMBLY.md](ASSEMBLY.md), 최종 CAD 검사는 [saved_audit.json](reviews/saved_audit.json)에 둔다. 공구 검사는 Wera 7mm 소켓의 외형 공간만 포함하며 내부 체결 깊이·연장대·손잡이는 확인하지 않았다. 테이블 외부 클램프·줄 예압 조절·관절 센서와 실제 구동 시험도 별도 남은 일이다.
