# 시험대 발 체결부의 조립 문제와 수정

첫 저장 CAD 검사(`initial_assembly_audit.json`)는 124부품의 9자세와 줄 11,160건에서 충돌0, 실제 접촉면72개 통과, 연산 오류0이었다. 그러나 발의 세로 나사4개를 위에서 삽입하는 머리 포락체가 이미 설치된 가로 클램프 나사와 겹쳤다. 겹침은 좌측 약1.1855mm³, 우측 약3.8150mm³이며 두 받침 위치에서 반복됐다. 따라서 첫 안의 전체 판정은 **실패**다.

`fixture_initial.py.txt`와 `audit_initial.py.txt`는 이 실패를 만든 당시 소스다. 생성 보고서와 원시 검사를 함께 보존한다. 당시 생성된 STEP/STL 전체는 D: 외부 개발 출력에 보존했으며 이 기록에 중복 복사하지 않았다. 현재 코드로 만든 최종 결과와 혼동하지 않는다.

수정은 시험대에만 적용했다. 부모 링크의 실제 접촉 패드와 손의 형상은 유지한다.

- 발 구멍·슬롯·체결물의 Y를 보강 띠 중심보다2mm 뒤로 옮겼다.
- 좌우 발 구멍 X를±29→±30mm로 옮기고 발 바깥쪽 끝을±34→±36mm로 늘렸다.
- 발의 Y 반폭을6→7mm로 늘려 옮긴 와셔를 지지했다. 공통판의 구멍은 발 좌표에서 함께 생성한다.

초기 치수 검토는 `MARGIN_REVIEW.md`에 남긴다. 그 문서는 X29의 중간 제안이며 최종 X30을 나타내지 않는다. X30에서 안쪽 슬롯 이동0.6mm를 따로 고려한 이상적 수직 머리 투영 여유는 좌측0.72019mm, 우측 나사 끝에 대해0.737924mm다. 추가 반경 유격0.2mm를 별도 보수적으로 차감해도 약0.520/0.538mm가 남는다. 이 계산은 명목 원통·직사각 투영식이고 조립체의 모든 공차를 합친 검증은 아니다.

최종 감사는 수정된 STEP를 다시 읽고 같은 자세·줄·접촉·접근 범위를 재실행한다. 특히 발 나사4개와 가로 나사의 완성 위치 및 머리 삽입 포락체 사이 최단거리를 실제 BRep에서 별도로 기록한다. 이 명목 거리 역시 소재 변형, 제작 공차, 토크나 실물 조립 승인을 대신하지 않는다.
