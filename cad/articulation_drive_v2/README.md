# 변경된 손 형상에서 제작·구동 개선

`webcam_articulation_v1`의 손 비율, 엄지 높이21mm·바깥 관절축, 깊은 주먹 경로를 그대로 사용한다. 원본 CAD와 현재 웹캠 앱을 수정하지 않고 별도 후보를 만든다. **현재는 제작·구동 승인 전이며, 남은 간섭과 외피·체결 문제를 결과에서 숨기지 않는다.**

![편 손·주먹과 내부 관절](generated/robot_hand_drive002.png)

## 실제 수정

- 기존 뿌리 링과 양쪽 포크를 하나의 회전 부품으로 연결하고, 지지살까지 합친 뒤 핀 구멍을 마지막에 관통 절삭한다.
- 고정 받침을 회전하는 손가락 눈 아래로 내리고, 벌림축의 두 쪽 부싱과 와셔·홈·유지링을 추가한다.
- 굽힘축에 머리가 있는 핀, 반대쪽 와셔·홈·유지링과 분할 플랜지 부싱을 넣는다.
- 각 고정 받침의 두 다리를 손바닥 바닥까지 연결하고, 관통 구멍·아래쪽 볼트·옆으로 넣는 너트를 모델링한다.
- 기존 뿌리30부품을 새100부품으로 대체한다. 전체190부품의 질량·관성은 실제 BRep에서 계산하며, 강체 소속을 각 부품에 명시한다.

구매품과 제조 공정은 확정하지 않았다. 부싱·클립·나사 형상은 공칭 설계이며, 나사산·끼워맞춤·클립 변형·강도·피로·볼트 예압을 검증한 부품 도면이 아니다. 특히 바닥 절삭 뒤 손바닥 강도는 다시 검토해야 한다.

## DRIVE002 검사 결과

- 전체190부품 모두 유효한 단일 솔리드. 실제 STEP/STL과 조립 STEP의 대응 및 시작/종료 입력 해시 확인.
- 편 손부터 주먹까지13개 표본에서 보고 기준을 넘는 겹침0, Boolean 실패0. 임의의20축 조합이나 연속 경로 전체의 보장은 아니다.
- 검지만−22° 벌리는 반례에는 다른 강체 간 겹침21쌍이 남는다. 이 자세를 없애거나 결과에서 제외하지 않았다.
- 뿌리 핀 통로·원통축·일체형 연결·좌면·바닥 체결의 선언한 형상 검사 통과. 너트10개의 삽입은 독립 검증에서19개 위치로 확인했으며, 전체 조립 순서·공구 접근·하중 전달은 미승인이다.
- 이전20모터 배치를 새 손과 비교하면 편 손·주먹에서 각각38쌍이 겹친다. 모두 검지 MCP 모듈11쌍·소지 MCP 모듈27쌍에 속한다. 이는 부품 쌍 수이며 모터38개라는 뜻이 아니다.

가정한 재료 밀도로 계산한 손 CAD 질량은 약724g, 그중 움직이는 부품은 약306g이다. 모터·줄·배선·누락 체결부가 빠져 있어 완성품 중량으로 쓰지 않는다. 다음 배치에서는 충돌하는 두 모터를 손목·전완으로 옮기는4개 손바닥+16개 원격 후보부터 검토하되, 공간·지지·줄 경로 확인 전에는 채택하지 않는다.

## 파일과 재현

| 파일 | 내용 |
| --- | --- |
| `build.py`, `root_module.py` | 원본 저장 STEP를 읽고 뿌리·손바닥 체결부만 수정. 입력 시작/종료 해시 확인 |
| [hand.step](generated/hand.step), [scene.json](generated/scene.json) | 조립 STEP와 명시적 강체·개별 STEP/STL·해시 대응 |
| [mass_inertia.json](generated/mass_inertia.json) | 부품별 실제 체적·질량 가정·세계 좌표 COM/전체 관성 텐서 |
| [assembly_review.json](generated/assembly_review.json) | 전체 부품 간섭·유한 핀 통로·원통축·좌면·체결 검사 |
| [packaging_screen.json](generated/packaging_screen.json) | 이전20모터 배치를 새 손과 편 손/주먹에서 비교 |
| [새20축 모델](../../sim/articulation_drive_v2/README.md) | 새 축·관성의 가정 전달계 계산과 한계 |

CadQuery/OCP, NumPy, SciPy, MuJoCo, Pillow 환경에서 `build.py` → `verify.py --poses path` → `packaging_screen.py` → `render.py` 순서다. Windows에서는 숨김 실행, 자식 프로세스 CREATE_NO_WINDOW, BLAS/OpenMP1스레드, D: 임시 폴더를 사용한다. 검증기는 원본 형상을 자동 수리하지 않는다.

`verify.py`는 개별 STEP와 조립 STEP를 다시 읽고, 모든 같은 강체/다른 강체 부품 쌍을 포함한다. 같은 강체 쌍은 강체변환 불변성을 이용해 중립 결과를 재사용한다. 주먹 경로13개 표본과 기존 검지−22° 벌림 충돌 반례를 검사한다. 이는 연속 경로 전체 또는 자유로운20축 조합의 무간섭 보장이 아니다.

## 아직 해결하지 않은 것

기존 접힘 홈의 국소 얇은 외피, 원위 핀/부싱 유지, 장식판·손끝 캡·덮개 체결, 자유 벌림의 손가락 간 충돌, 전체 줄 경로·풀리·예압 조절과 구동계 통합이 남아 있다. 기존20모터는 비교 검사 대상이며 이 손 조립에 실제 통합된 것으로 세지 않는다. 따라서 CAD 질량과 가정 전달계 추종 계산도 완성 하드웨어의50/100ms 성능 증거가 아니다.
