# 첫 후보의 실패 보존

첫 build_01/fit_01은 계산과 입력 해시 검사가 완료됐으나 물리 겹침 두 건으로 실패했습니다. 왼쪽 새 가이드가 기존 바닥 지지 나사와 149.659316 mm³, 위쪽 와셔와 44.185715 mm³ 겹쳤습니다. 이 결과는 통과 근거가 아닙니다.

첫 보고서, 해당 왼쪽 가이드의 실제 STEP, 검사 당시 소스를 보존했습니다. 전체 첫 생성물과 실행 로그는 D: 외부 작업 디렉터리에 남아 있습니다. 뒤의 후보는 Ø9.4 통과 공간을 추가하고 별도로 다시 검사합니다. 이 실패의 보고서를 새 후보 결과로 덮어쓰지 않습니다.

## 두 번째 조립 검사

`screen_02`는 158부품·세 중립 축 간격에서 정적 겹침0, 줄 검사4740건의 겹침0, 접촉306건·보조9항목·모듈 삽입4경로가 통과했습니다. 그러나 조립 선언168건 중9건이 막혔으므로 전체 결과는 실패입니다.

앞 덮개 나사 두 개를 부모 링크 받침 설치 후 넣으려 하면 받침과 부딪힙니다. 실제 순서는 모터/조절부 선조립 때 두 나사를 먼저 체결하고 이후 완성 모듈과 부모 받침을 설치하는 것으로 명시합니다. 긴50mm 조절 드라이버도 부모 받침에 걸렸습니다. 이 문제는 장애물을 제외해 처리하지 않고, 별도 짧은 조절키의 실제 형상과 접근을 새로 검사합니다.

`screen_02_audit.json`, 입력 생성 보고서·장면·당시 검사 소스를 보존합니다. `screen_02`는 세 중립 위치만 포함하며 아홉 관절 자세와 중간 조절 위치의 전체 검사가 아닙니다.
