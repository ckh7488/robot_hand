# 손 전체 운동 검사 기준 — MOTION001

사용자 요청: 수용한 손 비율을 유지하면서, 사람이 충분히 할 만한 손 움직임에 조금 더 여유를 준다. 손가락 단품 시험대보다 **전체 손의 간섭과 움직임**을 우선한다.

## 판정 원칙

- 지금의 제조 후보 `manufacturing_v2` 저장 STEP 359부품을 출발점으로 한다. 수용한 외형·축·길이·최신 엄지척 `[0,0,0,-15]°`를 보존한다.
- 자세를 움직여 보여주는 것, 공칭 재료 겹침 검사, 최소 간격, 경로 전체의 충돌 보증, 조립성, 구동 성능을 구분한다.
- 간섭하는 각도를 단순히 잘라내서 요구를 충족했다고 하지 않는다. 자세가 사람이 할 법한 동작인지 먼저 구분하고, 필요한 동작에서 발생한 자체 간섭은 설계 결함으로 남긴다.
- 관절끼리 최대각을 모두 독립적으로 조합한 20차원 상자를 '사람의 모든 자세'로 취급하지 않는다. 손가락 사이 의도된 접촉과 자기 관절 지지부의 막힘은 별개다.
- 되돌아오는 경로가 정확히 같은 강체 자세 경로라면 기하학적 겹침도 같다. 역순 재생을 별개 수천 건의 증거로 부풀리지 않는다. 실제 줄 유격·마찰·하중에 따른 방향 차이는 별도 시험이다.

## 필요한 움직임

1. 기존 보·바위·V·가위·엄지척·중지·산·록앤롤의 끝자세와 그 사이의 전환.
2. 손가락 개별 굽힘/펴기, 끝·가운데 마디 굽힘, 갈고리, 뿌리만 굽힌 탁자 모양, 평주먹, 자연스럽게 젖힘.
3. 편 상태의 벌림·모음과 굽힘 중 벌림 감소. 서로 관통하는 임의의 벌림 조합은 별도 스트레스 탐색으로 기록한다.
4. 엄지 펴기·모으기·대립, 손끝별 집기와 새끼 방향 이동, 끝마디의 팔목 방향 젖힘. 엄지 CAD 축을 임상 CMC 측정각과 일대일 동일시하지 않는다.
5. 각 필요 동작 주변의 여유 각도와 비접촉 외장 간격. 설계 여유 목표는 **5° / 비접촉 외장 0.5mm**로 두되, 이는 제작 공차 분석을 대체하지 않는다. 베어링/와셔 같은 의도된 접촉면에 0.5mm를 일괄 적용하지 않는다.
6. 사용자가 사진으로 추가 요청한 검지·중지 교차(🤞). 약지·새끼와 엄지를 접은 상태에서 두 손가락을 앞뒤로 분리한 뒤 교차하는 자세와 접근 경로를 별도로 검사한다. 정면 투영에서 X가 보이는 것만으로 실제 부품이 지나갈 수 있다고 판단하지 않는다.

## 이번 탐색의 각도

아래는 발견용 요구 범위이며 승인된 가동 범위가 아니다. 사람마다 가동 범위가 달라 전체 인구를 보증하지 않는다. 기본 범위에 5°를 더하고, 기존 PIP 135° 탐색 상한을 보존했다.

|축|기존 선언|이번 탐색|
|---|---:|---:|
|네 손가락 벌림|−22…22°|−27…27°|
|MCP(뿌리 굽힘)|−20…90°|−35…100°|
|PIP(가운데)|0…135°|−25…135°|
|DIP(끝)|0…90°|−15…95°|
|엄지 base sweep|−65…55°|−70…60°|
|엄지 opposition|0…85°|−5…90°|
|엄지 MCP|0…85°|−15…90°|
|엄지 IP|−20…85°|−25…90°|

일반적인 젖힘을 우선 확인하기 위해 별도로 MCP −20°, PIP −10°, DIP −5°를 검사한다. 이보다 큰 탐색 끝각에서의 충돌만으로 일반 자세가 불가능하다고 단정하지 않는다.

범위 참고: [Ibrahim 등, 2024, 390개 손의 능동 관절 가동 범위](https://pmc.ncbi.nlm.nih.gov/articles/PMC11436331/). MCP뿐 아니라 PIP/DIP의 뒤로 젖힘도 측정되었으며 개인차가 크다. 이 논문은 젖힘을 검사에 포함할 근거이고, 위 로봇 설계 범위나 여유를 인증하는 자료는 아니다.

## 승인 전에 남는 검사

- 발견된 자체 간섭의 국부 단면·체결/지지면 확인과 수정 형상의 재검사.
- 수정 후보에서 필요한 자세와 경로를 다시 검사하고, 연속 운동 구간별 보수적 간격 경계 또는 실제 회전 포락체로 표본 사이를 확인한다.
- 작은 간격과 내측 추력 와셔·자식 링크의 축방향 이동, 실물 공차, 전체 조립 순서/공구 접근 확인.
- 엄지 집기 때 손끝 위치뿐 아니라 접촉면 방향 확인. 현재 강체 손바닥의 오므림과 손가락 비틀림 자유도 부재도 별도 기능 한계다.
- 손 전체에 모터·줄·가이드·배선이 통합된 뒤 같은 경로를 다시 확인한다. 100ms 지연 목표는 그 이후의 동역학/실측 판정이다.

충돌을 발견한 결과만으로도 전체 가동을 승인할 수 없음을 알 수 있다. 일부 표본에서 겹침이 없다는 결과로 나머지 경로를 승인하지 않는다. 이번 자료는 제조 후보를 바꾸지 않는 발견/진단 체크포인트다.
