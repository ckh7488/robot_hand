# 원위 핀 유지 방식: M2 나사와 규격 와셔

결정일·공식 자료 열람일: **2026-10-25**. 기준은 `manufacturing_v1`의 원형 자유회전 원위 핀10개다. 이 문서는 후속 후보의 제작 조건을 정하며, 기존 CAD를 변경하거나 제조·하중·풀림을 승인하지 않는다.

## 선택과 이유

선택한 후보는 **Ø4 금속 핀 + M2×4 나사 + DIN9021 M2 대형 와셔**다. CAD에는 원위 핀10개에 적용하고, 실물 가공·조립 시험은 한 관절부터 시작한다. 나사가 와셔를 핀 끝에 고정하고, 기존 관절 스택에는 공칭 축방향 유격을 남긴다. 일체 머리와 오른쪽 keeper가 핀의 양방향 이탈을 막으며 핀의 자유회전은 유지한다. 구동 토크는 핀에 전달하지 않고 자식 링크/풀리에 전달한다.

E-ring은 얇고 나사 풀림이 없다는 장점이 있다. 이번 선택은 규격 E-ring이 기능적으로 부적합하다는 결론이 아니다. DE-3.2의 정확한 선정품 도면·설치 공구 윤곽·탄성 설치 조건이 미확정인 상태에서, 핀 끝의 확실한 좌면과 분해 가능한 체결을 먼저 시험하려는 선택이다. 나사 방식도 금속 가공·카운터홀드·풀림 방지라는 별도 요구를 가진다.

## 선택한 공칭 형상

X는 각 원위 핀의 로컬 축이고 단위는 mm다. 아래는 구매 완료나 실제 공급 공차의 확정을 의미하지 않는다.

| 부위 | 공칭 치수/위치 |
| --- | --- |
| 일체 왼쪽 머리 | Ø7, X −15..−13 유지 |
| 원형 핀 몸통 | Ø4, X −13..13.15; 기존 클립 홈 제거 |
| 기존 관절 스택 오른쪽 면 | X13.0; 왼쪽 머리가 좌면에 닿을 때 공칭 유격0.15 |
| keeper | DIN9021 M2, 외경7 / 내경2.2 / 두께0.8, X13.15..13.95 |
| 나사 | M2×0.4, 머리 아래 길이4, 머리 Ø3.8 / 높이2, 육각키1.5 |
| 나사 머리/끝 | 머리 X13.95..15.95; 끝 X9.95 |
| 핀 안 공칭 진입 | 4−0.8 = 3.2; 실제 완전 나사 물림 길이와 구분 |
| 조립용 내부 나사 표현 | Ø2.0 major-envelope, X8.75..13.15; 나사산 자체는 생략 |
| 실제 완전산 공칭 구간 | M2×0.4, 입구 모따기를 제외한 X8.75..12.75 = **4.0** |
| 공칭 완전산 겹침 | X9.95..12.75 = **2.8**; 수나사 끝 불완전산·공차를 제외하기 전 값 |
| 가공 전 입구 모따기 | Ø1.6→Ø2.4, X12.75..13.15, 축/반경 방향 각각0.4의45° 모따기 |
| 탭 전 드릴 | Ø1.6 원통 깊이6.0, X13.15..7.15; 선단각118°의 원뿔 길이 약0.48069, 끝 X6.66931 |
| 왼쪽 카운터홀드 | 머리 표면에서 폭1.0·깊이0.8의 열린 직선 슬롯; 공칭 드라이버 날0.8×4.0으로 접근 시험 |

keeper의 실재 공급 규격 예는 KRAFTBERG **K2.2/D9021-A2**다. 공급사 표는 A2 스테인리스, DIN9021/ISO7093와 위 세 치수를 명시하지만, 이번에 확인한 표에는 내외경·두께 공차가 없다. 공칭값만으로 최악 공차를 승인하지 않는다. [TME 공식 제품표](https://www.tme.eu/html/EN/washers-din-9021-stainless-steel-a2/ramka_20921_EN_pelny.html)

나사의 실재 규격 예는 Accu **SSCF-M2-4-A2**다. 공급사 공개값은 머리 지름3.8(−0.18/+0), 머리 높이2(−0.14/+0), 소켓 깊이1.0, 피치0.4, A2다. 나사 길이 공차·끝 불완전산·머리 밑 필렛과 실제 강도 등급은 공급 사양으로 추가 확인한다. A2라는 재질 명칭만으로 임의의 강도 등급을 부여하지 않는다. [Accu 공식 사양](https://www.accu.co.uk/metric-cap-head-screws/3790-SSCF-M2-4-A2)

## 가공 깊이와 실제 착좌

현재 숫자에는 명백한 축방향 공간 모순이 없다. 나사 끝X9.95는 완전산의 깊은 쪽 끝X8.75보다1.2mm 앞이다. **완전산 길이는4.0mm로 정정한다.** 실제 가공 전 모따기는 X12.75에서 시작하며, X12.75..12.95에서도 내나사 산봉우리 일부가 잘린다. 조립용 Ø2.0 구멍에서는 X12.95..13.15의0.2mm 모따기만 보이지만 이를 실제 완전산 입구로 삼아4.2mm라고 계산하면0.2mm를 과대계상한다. 이 정정은 기존 형상을 더 깊게 절삭하지 않고 가공 주석과 물림 길이 해석을 바로잡는 것이다.

Guhring의 해당 M2 절삭 탭 예는 선단2–3피치다. M2×0.4에서는0.8–1.2mm가 완전산 끝 뒤에 더 필요하다. 최대 선단은 X7.55로, 원통 드릴 끝X7.15보다0.4mm 앞에 위치한다. 이는 기하학적 여유 계산이며 칩 공간·탭 공차·재료별 가공 조건은 선택 공구와 제작자가 확정해야 한다. 성형 탭은 다른 선행 구멍 지름을 요구하므로 Ø1.6 절삭 탭 계획에 혼용하지 않는다. [Guhring 절삭 탭 공식 자료](https://guhring.com/media/catalogs/044mlrkbbek.pdf)

나사는 keeper를 **핀 끝**에 압착해야 한다. 관절 스택을 대신 압착하거나, 나사 끝이 막힌 구멍에 먼저 닿으면 의도한 체결이 아니다. pin-end/keeper 및 keeper/screw-head 좌면, 입구 모따기와 머리 밑 필렛의 여유, 나사 끝 여유를 따로 확인한다. 0.15mm 유격은 pin/head/bushing/washer 좌면의 최악 치수 합과 실측으로 확인하며 keeper 두께 자체는 핀 끝에 착좌하는 경우 이 유격을 직접 결정하지 않는다.

## CAD의 간이 나사 표현

조립 STEP에는 내부 나사를 **Ø2.0 major-diameter 구멍**으로, 수나사는 공칭 Ø2.0 원통으로 표현할 수 있다. 이것은 조립 외곽·축·깊이 확인을 위한 간이 인터페이스이며 실제 나사산이 아니다. 두 형상은 지정된 나사 구간에서만 대응해야 한다. 나사 쌍 전체를 무조건 충돌 검사에서 제외하지 말고, 비나사부·좌면·나사 끝·주변 부품은 실제 형상으로 검사한다.

별도 **machining blank STEP**에는 Ø1.6 원통과118° 드릴 선단을 보존하고 M2×0.4 절삭 탭, 완전산 깊이, 입구 모따기, 선행 구멍 깊이를 제작 주석으로 표시한다. 조립용 Ø2.0 구멍을 드릴 지름이나 완성 가공 치수로 전달하지 않는다. blank는 탭 전 공정 형상이며 완성 핀으로 표기하지 않는다.

간이 내부 구멍은 완전산 영역의 재료를 제거하고, 공칭 수나사 원통은 골을 채운다. 한편 탭 선단의 불완전산은 별도 형상으로 그리지 않았으므로 핀 전체의 질량을 엄밀한 상한/하한으로 단정하지 않는다. 이 차이는 부품별로 명시하고 조립 총 질량에서 서로 정확히 상쇄된다고 가정하지 않는다. 실제 나선 형상/가공 공차가 없으므로 나사 물림·인발·예압·회전 체결 경로·강도는 검증한 것으로 쓰지 않는다. 특히 Ø2 구멍의 직선 통과 검사를 실제 나사의 축방향 삽입 승인으로 해석하면 안 된다.

## 조립 검사 형상의 해석

핀·새 keeper·나사3개는 함께 축방향으로 움직이지만 기존 좌우 핀 와셔도 별도 구속되지 않았다. 공칭 유격을 `d=0.15`, 핀 이동을 `t`, 기존 좌우 와셔 이동을 `sL,sR`라 하면 `−d≤t≤0`, `t≤sL≤0`, `0≤sR≤d+t`다. 네 꼭짓점은 `(-d,-d,0)`, `(-d,0,0)`, `(0,0,0)`, `(0,0,d)`다. 기존 와셔의 공칭 외경7.4/내경4.1/두께0.6을 포함해 **5개 부품의 상관된 자유도**를 검사해야 한다. 이때 바깥 간섭용으로 각 축 이동의 합집합을 쓰면 보수적이지만, 내부 접촉은 상관 제약과 별도로 확인해야 한다. 기존 와셔와 핀의 반경 틈0.05, 베어링 틈, 실제 공급 공차는 이 축방향 모델에 포함되지 않는다.

[공구 게이지](tool_gauges.json)는 정렬된 공칭 팁과30mm 직선 접근, 두 공구의 공존을 확인하기 위한 선언 형상이다. 샤프트·손잡이에 여유를 줘도 미공개 팁 길이/전이부까지 실제 Wera 공구 전체를 덮는다는 보증은 아니다. 공구 접근은 핀머리와 기존 와셔를 좌면에 붙인 `t=sL=sR=0` 조립 자세로 명시한다. 이를 모든 유격 상태, 나사 회전 체결, 손으로 잡는 공간과 조립 지그까지 검증한 것으로 확대하지 않는다.

감사 보고서의 `completed`와 프로세스 정상 종료는 계산 완료를 뜻한다. 실제 간섭 통과 여부는 접근 실패·자세 간섭·연산 실패 수와 입력 해시 확인을 따로 읽어 판단한다. 가공 blank의 재수입/재구성 일치는 저장 형상이 선언한 구성과 같다는 증거이며, 실제 나사 가공·공구 적합성 또는 독립된 완성 나사 치수검사와는 구분한다.

## 다음 검증과 남은 제작 조건

1. **공구와 조립:** 핀 삽입→keeper→나사 순서, 왼쪽 슬롯 카운터홀드와 오른쪽 육각키의 동시 접근, 분해 경로를 검사한다. 슬롯 깊이0.8은 공칭 머리 잔여 두께1.2를 남기지만 공구 접촉·손상·체결 토크는 별도 시험한다. 새 머리 끝X15.95는 기존 핀 끝14.4보다1.55 길어져 주변 자세와 전환을 재검사한다.
2. **금속 핀과 와셔:** 내부 나사가 오른쪽 저널 위치까지 들어가므로 핀의 굽힘과 베어링 지지 상태를 다시 본다. Ø4에 내부 나사 최대 지름을Ø2로 잡으면 공칭 반경 벽1mm지만 이것만으로 강도 승인은 불가능하다. 재질·열처리 전후 가공 순서·동심도·저널 마감·와셔 평탄도와 눌림을 정한다.
3. **풀림과 윤활:** 체결 토크, 잠금 방법, 반복 사용 정책을 정한다. 저강도 고정제를 선택한다면 경화·해체를 실제 M2 재질/표면에서 검증하고 부싱 윤활부에 번지지 않게 한다. Henkel 자료의 M10 시험 토크는 M2 체결 토크가 아니다. 주변 플라스틱 적합성도 별도다. [LOCTITE 222 공식 TDS](https://datasheets.tdx.henkel.com/LOCTITE-222-en_GL.pdf)
4. **실물 확인:** 나사 체결 후 자유회전·축방향 유격·양방향 유지력, 반복 왕복 뒤 풀림·프레팅·유격 증가를 확인한다. 동역학이나100ms 추종 성능을 이 체결 변경으로 승인하지 않는다.

안쪽 추력 와셔20개와 자식 링크/부싱 묶음의 축방향 이동은 이번5부품 포락체의 범위 밖이다. 자식 링크를 공칭 위치에 고정한 국부 스택에서는 좌측 추력 와셔+0..0.05mm, 우측−0.05..0mm 여유가 있고, 자식 묶음 자체도 국부적으로±0.05mm 이동 여지가 있다. 실제 주변 구속과 상관된 이동을 확인하기 전에는 전체 실물 자유도를 포괄했다고 쓰지 않는다. 다음 관절 구동 후보에서 이 지지부·추력 스택도 함께 다룬다.

이번 결정은 규격 구매 부품을 이용한 다음 CAD/가공 후보의 방향이다. 형상 검사 통과, 실제 가공, 조립, 체결 유지력, 구동 시험은 각각 별도의 완료 조건으로 남는다.
