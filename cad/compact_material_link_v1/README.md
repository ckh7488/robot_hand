# LINK050 중단한 전체 재료 연결 연구

**이 단계는 사용자 전체 팔 배치 지적으로 중단했다. 채택·완료한 전달계나 손목/팔 운동 검증이 아니다.** PACK049 이후 모터·랙 위치를 고정한 국부 경로 확장은 재개하지 않는다. 최신 범위는 CHECKPOINT.json과 AGENTS.md를 따른다. 원래 실패·부분 결과·코드·그림은 보존한다.

PACK049 실제 모터출구/손목 보어와 기존 엄지 종단 사이에 두 피복·두 줄을 연결한 별도 연구다. 손397/기본364·모터16/랙/전기·OD와 기존 하드웨어862개는 그대로다. 새 하드웨어0, 중립 재료110행은 피복42/줄68의 수학적 분할이며110개의 설치 지지물이 아니다.

## 새 후보 길이와 근거

원래 MOTION047 피복698.964345153791/761.108456948670mm·줄853.356663204892/932.491923574900mm는 변경하지 않았다. 이번 별도 후보는 피복607.096127542183/643.981167525574mm·줄761.488445593285/815.364634151804mm다. 공급/절단 규격·최소 가능 길이나 실제 고정력 승인으로 쓰지 않는다.

[length_basis.json](reviews/length_basis.json)은 실제 새 포트와 기존 자연스러운 부모5·편손 손목8의13분석 조건에서 두 자유구간 현 길이 합의 필요 하한을 계산했다. 중립 연결 길이만 택하면 그 하한보다43.38503909/30.96541066mm 짧았다. 최대 필요 하한301.50075084855933/265.4712642391099mm에 중립 자체 굽힘의 현 초과분23.099817478236048/21.18249099928073mm를 더한 자유구간324.6005683267954/286.65375523839066mm를 한 번의 새 길이 시도로 명시했다. 이 여유는 성공 보장이나 최적 길이·텐셔너 규격이 아니다.13독립 현 분석을 같은 재료의13운동 성공으로 세지 않는다.

상류8/하류6의 원호 좌표와 두 선의 접촉 제약을 함께 썼다. 원호 분할은 설치 지지/텐셔너가 아니다. 실제 EI·중력·비틀림·힘·장력·마찰/예압·평형은 풀지 않았다.

## 실제 실패와 중단 범위

[첫 중립 결과](reviews/check.json)는 한 재료 상태의100815쌍/479AABB/3기록/연산실패0이다. 아래 피복과 이웃 middle_dip_actuator_motor의15.03362261575034mm³, 그 안쪽 줄과 같은 모터의0.7274137538437417mm³는 한 경로의 실제 막힘이다. 원래 아래 줄 연속 꼬리/감김 접합0.008502357297455174mm³도 그대로 기록했다. rawfalse를 같은 줄 분류로 덮지 않았으며 부모/손목 증분은 실행하지 않고 중단했다.

[실제 CAD 비교](images/connected_before_after.png)와 [실제 공통재료](images/actual_block.png)는 이 실패 후보의 그림이다. 양쪽 모든 하드웨어/팔 참고를 불투명 표시했다. 루프 외형 개선·수용/최적성의 증거가 아니다. 두 번째 그림의 같은 빨간 공통재료 확대는 별도 배율이다.

[표본 보강 결과](reviews/refined.json)는 같은 길이·하드웨어를 유지하고 그 한 원호의 접촉 표본을 늘렸으나 피복/같은 모터0.07472482470776817mm³가 남았다. 고정 표본만으로 사이 구간의 두께 접촉을 보장하지 못한 실패이며 원본을 보존했다. 첫 후보 실패와 이 실패를 성공 표본으로 합치지 않는다.

[후속 부분 결과](reviews/continuous.json)는 해당 한 원호 전체와 실제 모터 SOLID의 native 최근접 거리를 제약으로 추가한 연구다. 피복 반경1.5mm를 그대로 쓰며 새0.5/1mm 여유·OD/R 변경은 없다. 다른 자유 원호 전체의 접촉 보장은 아니다. whole_arc_neutral과 whole_arc_parent_5의 각5외부+내부 결과/저장 CAD는 있지만 whole_arc_parent_10은 외부5그룹까지만 저장했다.10%의 내부 검사·CAD 저장 전 의도 중단했고 보고서 completed=false를 유지한다. 전체 부모/풀기/손목·팔꿈치·전완 회전 성공이 아니다.

실행 중단은 도구 오류를 고쳐 재시작하라는 뜻이 아니다. history의 user_interruption.json과 원래 status/stdout/오류를 먼저 읽는다. 대기 중이던 추가 하드웨어 검사·렌더도 중단했다. check_hardware.py, render_continuous.py, review_core.py는 미실행 초안이다. 정확SHA 재검사를 마친 LINK050 완료 단계로 표기하지 않는다.

첫 배열 도우미 파일의 괄호 문법 오류는 CAD/입력기하/native 전에 중단했으며 history에 원문/오류를 보존했다. 수정 후 compact_model.py로 분리해 기존 다른 단계의 link_model 모듈과 이름 충돌을 피했다. 이전 실패나 모든 곡면/STEP 비교 보류는 해소하지 않았다.
