**기존 형상 그대로 앞나사 두 개를 기울여 넣는 60표본이 통과했고, 뒤나사·출력나사까지 지지부22행의 조건부 선조립을 마쳤다. 첫모터 몸체와 너트 복구 뒤 고정나사 진입이 자체 base_nuts에 걸려,전체16묶음 복구는 미완이다.**
