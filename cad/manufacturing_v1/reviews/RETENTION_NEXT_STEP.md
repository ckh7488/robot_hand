# 다음 제작 검토: 원위 핀의 규격 클립과 홈

검토일·공식 자료 열람일: **2026-10-25**. 이 문서는 읽기 검토 결과이며 현재 CAD·코드를 변경하지 않는다. `manufacturing_v1`은 원형 자유회전 핀과 원형 왼쪽 부모 부싱을 적용하지만, **기존 자체 형상 클립의 탄성 설치·빠짐하중·수명을 승인하지 않는다.**

## 현재 저장 형상

원위 관절 10개가 같은 공칭 치수를 사용한다. 아래 X는 각 관절의 로컬 핀 축이다. [기존 핀·와셔·클립 정의](../../gesture_hand_v3/fabrication_repairs.py#L333), [현재 원형 핀 후보](../build.py), [해석 범위](../design_patch.json)를 기준으로 했다.

| 항목 | 현재 CAD |
| --- | --- |
| 핀 본체 | Ø4, X −13~14.4mm |
| 일체 머리 | Ø7, X −15~−13mm |
| 홈 | Ø3.2, X 13.1~13.9mm, 폭0.8mm |
| 홈 바깥 끝부터 핀 끝까지 | 14.4−13.9 = **0.5mm** |
| 자체 클립 | 외경7.0mm, 원형 내경3.3mm에 입구2.6mm 절삭, 두께0.7mm, X 13.15~13.85mm |
| 오른쪽 핀 와셔 | 외경7.4/내경4.1mm, X 12.4~13.0mm |
| 공칭 좌우 외측 스택 | X −13~13mm; 현재 표시된 클립 왼쪽 면까지 여유0.15mm |

클립의 재료는 `steel_nominal_assumption`, 밀도7.85×10⁻⁶kg/mm³뿐이다. 강종·열처리·표면처리·구매 품번·치수 공차는 정해지지 않았다. 입구2.6mm가 홈Ø3.2를 통과하려면 탄성 변형이 필요하다. 완성 위치의 무교차나 회전 포락면 검사로 이 설치 과정과 유지력을 대신할 수 없다.

## 실제 규격품 후보와 차이

아래 수치는 같은 제조사의 공식 제품 자료를 사용했다. 서로 다른 공급사나 표면처리의 공차를 섞어 적용하지 않는다.

| 항목 | [Rotor Clip DE-3.2 / DIN6799](https://www.rotorclip.com/product/de-3-2/) | [Rotor Clip DSH-4 / DIN471](https://www.rotorclip.com/product/dsh-4/) |
| --- | --- | --- |
| 적용 축 지름 | 4.0~5.0mm | 4.0mm |
| 홈 지름 | 3.130~3.200mm | 3.760~3.800mm |
| 홈 폭 | 0.640~0.690mm | 공개값0.500mm; 상세 공차는 도면 확인 필요 |
| 링 두께 | 0.580~0.600mm | 0.350~0.400mm |
| 홈 바깥 끝의 최소 축 여유 | 1.000mm | 0.300mm |
| 외곽·설치 | 자유 외경6.9mm, **장착 여유 외경7.3mm**, 옆에서 삽입 | 축 끝에서 확대하여 삽입; 러그 높이2.2mm·공구 구멍Ø1.0mm. 실제 전체 포락면은 공급사 CAD 확인 필요 |
| 명시된 공구 예 | A-310 계열 삽입기 | RPA-0 계열 플라이어 |

현재 Ø3.2 홈은 DE-3.2의 지름 범위에 해당하지만 **폭0.8mm와 끝 여유0.5mm는 해당 권장 치수에 맞지 않는다.** DSH-4는 홈 지름·폭을 모두 바꿔야 하므로 현재 홈에 그대로 사용할 수 없다. 두 제품 모두 카탈로그상의 실제 품목이지만 이번 검토는 재고·납기·구매 확정을 포함하지 않는다.

공식 자료는 도금품의 최대 두께에0.05mm를 더하도록 안내한다. 따라서 표의 기본 두께를 임의의 도금 품번에 그대로 적용하지 않는다. 홈의 하중측 바닥 모서리 반경, 맞닿는 와셔의 모따기 및 해당 하중 조건도 선정한 정확한 제품 도면으로 확인해야 한다. 서로 다른 위치의 반경·모따기 제한을 혼동하지 않는다.

## 권장하는 다음 독립 후보 — 아직 CAD에 미반영

우선 엄지 IP 한 곳에서 **정확한 DE-3.2 품번·재료·표면처리와 공급사 장착 CAD를 고정**하고 다음을 함께 검토한다. 공급사 링을 자체 C형 클립의 외경만 바꾼 형상으로 대체하지 않는다.

- 홈 시작 X13.1mm와 기존 와셔·관절축은 유지하고, 홈 지름·폭을 선택 제품의 공차에 맞춘다.
- **핀 끝 X15.0mm**를 시험한다. 이는 현재 X14.4에서0.6mm 늘리는 **후속 제안이며 구현되지 않았다.** 홈 폭 최댓값0.69mm일 때도 홈 끝13.79→핀 끝15.0의 여유는1.21mm다. 실제 핀 길이·홈 위치의 가공 공차는 별도 배분한다.
- 기존 클립의 Ø7.0 포락면 검사 결과를 승계하지 않는다. 새 장착 외경Ø7.3과 선정 제품 공차에 맞춰 핀·클립의 회전 및 모든 관련 자세를 재검사한다.
- 링이 홈 바깥 벽에 닿는 조건에서, 오른쪽 와셔 면 X13.0까지의 공칭 여유는 `13.1 + 홈 폭 − 링 두께 − 13.0`이다. 위 제품 범위만 대입하면0.14~0.21mm다. 이는 다른 부품·좌면·홈 위치의 공차와 변형을 포함한 전체 유격 보증이 아니다.

핀 끝 연장을 피해야 한다면 DSH-4가 대안이다. 예를 들어 홈 시작13.1과 공칭 폭0.5를 쓰면 현재 핀 끝14.4까지0.8mm가 남는다. 그러나 러그, 링 확대 과정과 플라이어 접근 공간을 새로 확인해야 하며, 이 예도 아직 CAD에 반영하지 않았다.

## 다음 통과 조건

1. 구매 전에 정확한 공급사 CAD·최종 치수 도면, 재료/열처리·표면처리 규격과 필요한 성적서·추적성 자료를 확인한다. 실제 축방향 하중·충격·반복 수명을 정하고 그 조건으로 링과 홈을 검토한다. 카탈로그 하중을 현재 핀 재료·홈·와셔에 그대로 승계하지 않는다.
2. 부싱·와셔·핀·클립 순서와 분해 경로를 정한다. 열린 손 또는 손가락 하위 조립 상태에서 실제 링 및 [공식 삽입 공구](https://www.rotorclip.com/retaining-rings/retaining-ring-tools/ring-applicators-dispensers/)의 접근·이동 여유를 확인한다. 링의 완성 위치와360° 회전 포락면은 공구 접근 및 설치 경로와 별개의 검사다.
3. 클립의 **유한 탄성 변형·안착·탈락·재사용성은 현재 미검증**이다. 규격품의 설치 지침을 적용하고 실물에서 안착과 축방향 유지력을 확인한다. 자유회전 핀의 마찰 분배·프레팅·유격 증가도 별도 시험한다.

이 문서는 다음 부품 선택과 CAD 수정의 근거다. 현재 클립 또는 미래 교체안의 제조·강도·구동 성능 승인서가 아니다.
