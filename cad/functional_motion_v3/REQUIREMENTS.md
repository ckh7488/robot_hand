# FUNCTION003 · 전체 기능 우선 검사

2026-10-26 최신 사용자 지시: 실동작을 막는 주요 문제와 사람이 하는 어려운 동작을 우선한다. 작은 간격과 임시 설계 여유의 미달은 나중에 다룬다. 이전 9손짓이나 사용자가 준 예만으로 범위를 닫지 않는다.

## 검사와 수정의 우선순위

1. 필요한 접촉·교차·손모양에 도달할 수 없는 문제. 관절축·자유도·손바닥 형상 때문에 필요한 기능을 만들지 못하는지 확인한다.
2. 필요한 접근·완성·놓기 경로에서 실제 CAD 재료가 겹치거나 움직임이 막히는 문제. 끝자세가 좋아도 경로가 막히면 미완이다.
3. 힘 전달·조립에 확실한 결함이 있는 문제. 반복되는 실제 실패와 기능 영향이 큰 순서로 수정한다.
4. 작은 공칭 틈, 추가 각도 여유, 미확인 공차 위험은 별도 주의로 보존한다. 해당 숫자만으로 기능 실패를 선언하거나 같은 국부 검사를 반복하지 않는다.

접촉이 필요한 집기·교차와 재료 관통은 다르다. 접촉을 제거하려고 기능을 못 하게 만들지 않으며, 간섭 부품을 검사에서 빼거나 각도를 잘라 문제를 숨기지 않는다.

## 능동적으로 넓힐 기능

- 교차/표현: 검지·중지의 두 교차 방향, 가까이 감기는 교차, OK, 손가락 하트, L, 엄지·새끼 펼치기, 손가락 수 표현과 기존 손짓.
- 개별/협응 운동: 각 손가락 굽힘·펴기, 갈고리·탁자·평주먹·주먹, 순차 탭·물결, 편 상태와 굽힌 상태의 벌림·모음.
- 엄지: 네 손가락 손끝과의 집기, 검지 옆면의 열쇠 집기, 중지/새끼의 여러 마디와 손바닥 쪽 대립. 접촉점 위치와 표면 방향을 함께 본다.
- 파지: 연구의 GRASP33개 정적 파지를 빠짐없이 커버리지 목록에 올린다. 작은/큰 원통·구·판, 세 손가락·필기·열쇠·카드·가위형 잡기를 실제 물체 크기와 접촉 부위로 정의한다. 이름이나 비슷한 각도만 생성해서 그립 성공으로 세지 않는다.
- 전환/조작: 열린 손→접근→완성→놓기, 손짓 간 전환, 손안 물체 옮기기·굴리기·손가락을 바꿔 잡기. 아직 통합되지 않은 줄/모터/힘·마찰은 별도 미검증으로 둔다.

## 판정

각 동작은 기능 목표, 공학적 후보각/경로, 최신364부품 입력 해시, 검사 단계와 실제 결과를 기록한다. 연구에서 직접 얻은 동작 범주와 우리가 만든 로봇 후보각을 구별한다.

상태는 미정의/미검사, 기하 도달 후보, 목표 형태/접촉 실패, 실제 재료 간섭, 표본 경로 미완, 작은 틈 주의, 실물 미검증으로 나눈다. 단순 충돌0을 손짓·집기 성공으로 승격하지 않는다. 접촉 후보를 실제 물체 유지나 힘/수명 검증으로 쓰지 않는다.

교차는 정면의 X뿐 아니라 교차점 근처 앞뒤 간격과 실제 표면 접근을 본다. 기존 약49.9mm 중심선 간격은 비교 기준의 미완 후보다. 더 가까운 후보를 찾되, 밀착 정도의 임시 수치를 생체 표준처럼 쓰지 않는다.

정적 파지33분류는 한 손의 정적·안정 파지를 위한 분류이며 교차·비파지 손짓·손안 조작 전체를 포함하지 않는다. 따라서 별도 기능을 추가하며, 목록의 개수로 모든 인간 동작을 검사했다고 주장하지 않는다.

기준 형상은 `cad/motion_clearance_v2/generated/assembly_catalog.json`의 손364부품이다. 별도 시험대33부품은 손에 설치된 부품이 아니다. 외형·축·길이는 이번 범위 확장에서 바꾸지 않는다. 실제 필요한 큰 수정은 전체 기능 결과를 보고 선정한다.
