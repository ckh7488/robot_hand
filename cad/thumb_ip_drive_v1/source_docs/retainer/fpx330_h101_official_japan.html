Features

- DYNAMIXEL X330 exclusive hinge frames and idler set

- Manufactured with high strength of engineering plastic

- Can be affixed tightly using bolts and nuts

- Grooved for tidy wiring and nut fastening

- It packaged in a hinge frame and idler bearing set.
