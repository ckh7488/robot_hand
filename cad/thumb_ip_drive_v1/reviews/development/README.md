# 개발 중 발견한 실패 보존

이 폴더의 JSON은 중간 후보의 원시 보고서 사본입니다. `index.json`은 원래 D: 작업 경로와 파일 해시를 기록합니다. 원래 작업 CAD·스크립트는 해당 작업 폴더에 보존되어 있으며, 이 기록 전체를 현재 커밋만으로 재실행할 수 있다는 뜻은 아닙니다. 최종 후보의 저장 STEP 재검사는 상위 폴더의 별도 감사 보고서를 사용합니다.

| 기록 | 발견과 처리 |
| --- | --- |
| invalid_child | 부울 연산 뒤 잘못된 솔리드 방향·음수 체적이 발생. 절댓값으로 성공 처리하지 않고 비파괴 순차 연산과 각 단계 유효성 검사로 교체 |
| four_bolt_interference | 단일 솔리드가 유효하더라도 고정판·나사가 기존 끝마디와 겹침. 나사 배치를2개로 변경 |
| closed_passage_thin_lip | 줄용 긴 원통 구멍이 실제로는 외피를 열고 얇은 가장자리를 남김. 외측 열린 홈으로 변경 |
| open_slot_probe | 열린 홈으로 바꾼 국부 검토. 가공 공구가 별도 검은 덮개를 지나가므로 부품 단독 가공·덮개를 뺀 상태의 줄 배치를 명시 |
| cap_support_cut_failure | 드라이버 통로를 넓히면 손끝 덮개 지지부가 깎임. 지지부를 보존하는 중앙 나사 위치로 변경 |
| screw_entry_failure | 공구가 들어가더라도 나사 머리의 실제 삽입이 상부 벽에 막힘. 별도 상부 진입 창 추가 |
| assembly_window_probe | 작은 진입 창을 거치는 두 단계 삽입 경로. 최종 홈 공구 반경 수정 전 기록이므로 최종 CAD 통과로 승계하지 않음 |
| native_axial_support | 원래 핀·부시·와셔 지지부의 명목 축방향 구속 검토. 새 줄 구동부의 모든 유격·경사·하중 검증을 대신하지 않음 |
| pre_exit_saved_audit | 첫 전체 후보의 손80관측과 모터 중립에서는 보고 기준 이상 충돌이 없었지만, 실제 굵기의 줄과 끝마디 홈 출구가10건 겹침. 특히 IP85°의 한쪽 직선 줄은 약0.433mm³ 침범하여 최종 통과로 사용하지 않음 |
| exit_order_tail_failure | 출구 절삭을 앞 단계로 옮겨 정상 부품을 얻었으나 꼬리 홈10건의 작은 교차가 남음. 복잡한 이전/새 형상 간 차집합 실패도 미확인으로 보존 |
| flat_tail_local_probe | 꼬리를 평탄 U홈으로 바꾸어 국부 줄30건 교차0, 보어·좌면·줄 바닥 변화0. 이때 전체 차집합도 성공했으나 최종 전체 손·모터·조립 검사를 대신하지 않음 |
| bench_fastener_span_failure | 확장한 v2 검사에서 손80관측과 모터 회전부/고정부1,000쌍은 통과했으나, 고정 직선 줄과 벤치 M3 나사 한 개가5자세 모두 약0.04825mm³ 겹침. 최종 통과로 사용하지 않음 |
| bench_fastener_relocation_probe | 네 번째 체결축을 X4→-4mm로 이동해 모터 중립528쌍·회전부/고정부1,000쌍·줄/모터990건 교차0. 선언한 공구 게이지와 체결 좌면도 확인. 실제 구매 공구·나사 규격 공차나 강도 승인과 구분 |
| bench_fastener_seat_probe | 이동한 네 번째 포스트의 베이스 접촉면만 분리해 명목 환형 면적29.4053mm²와 일치 확인. 하중·강성 검증은 아님 |

일부 초기 스크립트의 `completed` 또는 종료 코드0은 계산 종료만 뜻합니다. 원시 교차 목록과 `core_gate`/`bounded_candidate_pass` 등 해당 판정 필드를 함께 읽어야 합니다. 이 후보부터 최종 감사는 `completed`, `passed`, `errors`, 입력 해시와 원시 실패 목록을 함께 확인합니다.
