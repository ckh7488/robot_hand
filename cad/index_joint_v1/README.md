# 검지 뿌리 1축 CAD · 배선·체결 검토 2차

## 먼저 볼 파일

- index_root_joint.FCStd / index_root_joint.step: 수정한 1축 상세 후보. 고정부와 회전부, 나사, 배선 공간을 분리했다.
- set_joint_angle.FCMacro: FreeCAD에서 -20~100도 회전. 이 매크로는 기구 각도만 바꾸며 모터를 제어하지 않는다.
- assembly_preview.png: 위 1축의 실제 CAD 형상과 배선 외곽 렌더.
- whole_assembly_overview.png: 손·손목·전완의 정면/사선/측면.
- whole_hand_closeup.png: 손바닥/손등/손 사선.

**전체 이미지의 구조는 기존 24축 배치 초안이다. 이번 상세 체결·배선은 아직 1축 시험 모듈에만 반영했다.** 전체 손을 제조 가능한 CAD로 끝냈다는 뜻이 아니다. 전체 화면의 주황 부분은 상세 검토 중인 검지 뿌리의 위치 표시다. 팔 모터는 공칭 외곽이다.

현재 Flat 자세의 손바닥판은 196 x70 x6mm, 엄지와 브래킷을 포함한 손 외곽은 약290 x283 x131mm다. 인체 70% 축소 손이 아니라 모터 직결 배치에서 나온 큰 초안이다. 보기별 확대율은 다르다.

## 이번 변경

1. 임의의 소형 머리 M2 볼트 요구를 실제 규격 **NBK SNZS-M2-6**으로 고정했다. M2x0.4, 길이6mm, 머리 지름3mm/높이0.6mm, 십자0번이다. 제조사 최대0.22N·m는 볼트의 상한이며 플라스틱 조립 권장 토크로 사용하면 안 된다. 실제 조임 토크는 미정이다.
2. 모터 커넥터의 핀·플라스틱 단면을 확인해 **손등 쪽 포트에서 회전축 -X 방향으로** 빼도록 정했다. 포트가 측면에 보인다고 옆으로 삽입하는 커넥터는 아니다. 이전 메모의 ‘S101이 포트를 막으므로 반대 포트만 사용’ 해석을 바로잡았다.
3. 플러그 외곽과 S101 사이 공칭0.1mm는 여유가 부족해, **S101에 10.1 x11.5mm 케이블 창을 추가**했다. 기성 프레임을 그대로 쓰는 부품이 아니며 후가공이 필요하다. 원본 STEP은 sources/에 보존한다. 가공 후 강도는 아직 확인하지 않았다.
4. 3가닥의 고정 배선 경로와 케이블 가이드를 추가했다. 22AWG, 피복 외경1.9mm 이하 기준이고, 경로의 중심선 굽힘 반경은10/12.5/15mm다. 이는 설계 공간이며 케이블 제조사의 동적 굽힘 수명 보증값이 아니다.
5. M3x16 한 개와 아래쪽 M3 너트로 가이드를 기존 받침 홀에 고정한다. 가이드의 슬롯에 2.5mm 케이블 타이 하나를 넣어 선을 묶는다. 타이는 형상 모델에 포함하지 않았다.

joint_hardware_spec.json이 새 하드웨어·배선의 치수 기준이다. 전선 색은 경로 구분용이다. 실제 핀 순서는 ROBOTIS 매뉴얼의 GND/VDD/DATA와 실물 커넥터 방향을 대조한다.

## 구조·조립 순서

XL330 몸통 → 창을 낸 S101 → 시험 받침으로 고정한다. 출력 혼과 반대 아이들러에는 H101 힌지를 양쪽으로 체결하고, 시험 링크를 붙인다. 원점은 혼/아이들러 접촉면 중간, +X는 회전축, +Y는 손가락 방향, +Z는 손바닥이다.

1. 모터를 넣기 전에 S101 안쪽에서 SNZS-M2-6 네 개를 넣고, 받침 바깥에서 너트를 조인다.
2. H101 안쪽에도 같은 볼트 네 개를 넣고 시험 링크의 외부 너트를 조인다. 모터를 끼우기 전에 해야 안쪽 드라이버가 들어간다.
3. 모터와 S101을 몸통용 M2x8 TAP 네 개로 고정한다. 플러그/핀은 이 단계에서 결합 상태를 눈으로 확인한다.
4. 제조사 절차대로 아이들러·캡·중심 나사를 설치하고, H101을 혼/아이들러 양쪽 M2x4 TAP 네 개씩으로 체결한다.
5. 선은 -X로 빼고, 회전부 바깥에서 뒤쪽(-Y)으로 돌려 가이드에 고정한다. 모터가 고정되어 있으므로 이 경로 자체가 관절마다 구부러지는 구조는 아니다. 다음 마디 모터로 넘어가는 배선은 아직 설계하지 않았다.

## 검사 결과와 한계

- CAD 54개 부품의 BRep가 유효하고 STEP/FreeCAD 재열기 형상·회전축이 일치한다.
- 기존 5개 자세(-20/0/45/70/100도)의 주요 3쌍 간섭 검사를 다시 했다. cad_validation.json에 기록한다.
- 선을 반경0.3mm 더 굵게 가정한 상태에서도 몸통과 수정 프레임 사이에 약0.75mm가 남는다.
- 회전부 뒤쪽 형상이 반경8.5mm 원통에 포함되는지 실제 CAD로 검사하고, 회전에 따른 반경 불변·축 방향 분리를 이용해 **고정 배선은 -20~100도 전체에서 회전부와 분리됨**을 확인했다. 보수적 하한은 cable_validation.json에 기록한다. 끝점/중간 자세에서는 실제 BRep 거리도 따로 확인했다. 제조 공차 전체나 케이블의 탄성 변형을 인증하는 결과는 아니다.
- 플러그 외곽–수정 프레임 간격은 약1.005mm다. 수정 전0.1mm와 구분한다.
- **닫히지 않은 항목: 실제 플러그 결합 형상.** JST 공개 도면으로 만든 보수적인 직육면체는 모터 뒷커버와0.64mm3 겹친다. 실제 중공 하우징의 상세 STEP이 아니므로 실제 간섭인지 외곽 단순화 때문인지 확정하지 않았다. 이 값을 숨기거나 ‘모든 부품 조립 통과’로 표시하지 않는다. 실물 EHR-3의 키·핀 결합·삽입 깊이를 대조해야 한다.

추가로 남은 것: 프레임 창 가공 후 강도, 프린터 공차, 반복 하중, 재료/인서트, 다음 관절 배선, 전체 손 전원 분배와 실제 서보 응답. **제조 최종본이나 사람보다 빠른 모방 성능 입증본이 아니다.** 기존 손의90개 경로·속도 결과는 이 새 상세 모듈의 검증으로 재사용하지 않는다.
