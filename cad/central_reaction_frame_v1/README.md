# ARM061 중앙 반력 프레임 후보,미채택

**드럼 ±90°의 기존 중앙 허브 걸림을 피했지만,보수적 전회전 공간의 기존 클램프 침범과 새 연결살의 나사 간섭이 남아 미채택이다. 실제 전완 회전 출력의 허브·체결 모델도 아직 없다.**

## 실제 변경과 유지
