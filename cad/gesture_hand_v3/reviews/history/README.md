# 수정 전 통합 검사의 기록

`initial_endpoints.json`과 `initial_interfaces.json`은 같은 최초 349개 부품의 저장 STEP을 읽은 완료 검사다. 각각 입력 해시의 실행 전후 일치를 확인했다. 최종 후보의 결과는 상위 폴더의 보고서를 따른다.

선언한 공칭 체결 검사는 통과했지만 전체 부품 쌍 검사에서 엄지 부싱·와셔와 외피의 간섭, 접은 약지 끝과 덮개 볼트의 간섭, 주먹·엄지척의 손가락 간 간섭이 드러났다. 체결 검사 통과만으로 전체 손의 간섭을 통과시킬 수 없다는 수정 전 근거다.

`initial_build_report.json`과 `initial_poses.json`은 당시 생성·자세 정의다. 보고서에는 원래 입력의 해시가 남지만 이 폴더는 당시의 전체 CAD 사본을 포함하지 않으므로 최종 CAD로 이 수치를 재현한다고 주장하지 않는다. 최종 커밋은 최종 입력에서 별도로 재구축·핵심 재검사한다.

`thumb_pose_selection.json`과 `fist_pose_selection.json`은 최초 조립에서 엄지의 목표 자세만 바꾼 선택 근거다. 엄지와 관련된 서로 다른 강체의 쌍만 대상으로 했고 당시 공통 조립 간섭은 통과시키거나 숨기지 않았다. 선택한 주먹의 원래 충돌3쌍에서는 최소2.07575 mm를 확인했으나 전체 손 최소 간극이 아니다. 최종 판정은 수정된 전체 조립의 아홉 자세 검사에서 한다.

`local_interface_regression.json`은 이전 저장 STEP 일부에 최종 국부 수정 함수를 적용한 작은 회귀 검사다. 최종 저장 조립의 전체 검사와 구분한다. 이 탐색·국부 검사의 D: 작업 경로는 당시 이력이며 현재 생성기의 필수 입력이 아니다.
