# FORM002 형상을 유지한 아홉 자세 검토

수용한 [FORM002](../accepted_form_v1/README.md)의 손바닥 180×150 mm, 엄지 65 / 50 / 52.6033 mm와 네 손가락의 길이·뿌리 위치·20개 관절축을 유지했다. 이번 단계에서는 실제 관절·체결 형상을 다듬고 **아홉 목표 자세의 저장 CAD에서 기준치 이상의 부품 겹침 0건**을 확인했다. 결과를 보여준 뒤 추가 개선은 잠시 멈춘다.

산 모양은 엄지·중지·새끼를 편 자세다. 록앤롤은 검지·새끼를 펴고 엄지를 접은 모습과 편 모습을 각각 검사했다. V는 검지·중지의 끝 방향 차이24°, 가위는2°로 구분한다. 표는 목표 자세의 정적 검사 결과이며 이동 중 경로의 통과 판정이 아니다. 수정 전에는 모든 자세에 공통으로 포함된 조립 간섭도 있었으므로 각 행의 수를 서로 더하지 않는다.

## 실제 수정

- 다섯 뿌리 관절의 지지·핀 유지·손바닥 체결을 구성하고, 엄지 받침과 바닥 너트의 겹침을 수정했다.
- 원위 힌지10개의 실제 핀·부싱·클립, 덮개 체결6개, 외피 판12개와 손끝 캡5개의 체결 구조를 추가했다. 타원으로 변형된 시각용 핀을 실제 원형·D형 부품으로 대체했다.
- 엄지 부싱·와셔의 국부 여유와 약지 끝에 닿던 덮개 나사를 수정했다. 손가락·손바닥의 큰 비율을 바꾸어 충돌을 숨기지 않았다.
- 주먹·엄지를 접은 록앤롤의 엄지 위치를 조정했다. 엄지척은 뿌리를 바깥으로 빼고 다음 관절을 굽혀 끝을 세워, 접힌 검지와 분리했다.

현재 주먹의 엄지 네 각도는 [-2.224, 58.952, 50.415, 78.626]°, 엄지척은 [-10, 20, 40, 0]°다. 원본 FORM002의 각도·33개 참고 프레임은 그대로 보존하고, 수정된 목표와 후보 경로는 `poses.json`에 별도로 기록한다. `design.json`의 원본 `fist_deg`/`fist_path`와 현재 `gesture_candidate_pose_catalog`를 구분한다. [국부 구조와 재료 가정](FABRICATION_REPAIRS.md)

## 확인한 범위와 남은 일

최종 조립은 유효한 연결 단일 솔리드 349개다. 검사기는 저장 STEP을 다시 읽어 해시·부품 체적·경계·조립 순서를 대조하고, 같은 강체와 다른 강체의 부품 쌍을 모두 포함했다. 재료 교집합0.02 mm³ 초과를 겹침으로 보고하며 Boolean 공차는0.000001 mm다. 이 실행은 근접 거리 계산을 생략했으므로 전체 최소 간극을 보증하지 않는다. [자세 검사](reviews/gesture_endpoints.json)

선언된 공칭 체결 검사도 통과했다: 원통 구간 20개 중 실패 0개, 접촉 좌면 192개 중 실패 0개, 회전방지 평면 40개 중 실패 0개, 실제 부품 통로 16개 중 실패 0개, 덮개 체결 6개 중 실패 0개, 외피·손끝 체결 34개 중 실패 0개. 뿌리 관절의 선언 인터페이스와 너트 좌면도 따로 통과했다. 실제 부품의 맞닿는 좌면·핀 통로·유한 원통 구간을 검사한 결과이며, 조립 공차·강도·피로·나사산·클립 탄성·모든 공구 접근까지 승인한 것은 아니다. [체결 검사](reviews/fabrication_interfaces.json)

**자세 사이의 중간 동작과 전 가동 범위는 이번 최종 검사에 포함하지 않았다.** 저장된 전환 경로는 후속 검사용 후보이고 `fraction`은 경로 위치이며 시간이 아니다. 모터·줄·배선·전완을 통합한 구동계와 실물 시험도 남아 있다. 이전 후보의 동역학 결과를 승계하지 않으며 로봇 단독100 ms 이하 지연을 이번 결과로 주장하지 않는다. 렌더는 저장된 실제 CAD 부품을 움직여 만든 것으로 모양 확인 자료다.

## 재현

저장소 루트에서 해당 CAD Python 환경을 사용한다. Windows에서는 AGENTS.md에 따라 숨김 실행·D: 임시 파일을 사용한다.

```text
python cad/gesture_hand_v3/build.py --stage fabrication
python cad/gesture_hand_v3/audit_gestures.py --cad-root cad/gesture_hand_v3 --poses cad/gesture_hand_v3/poses.json --mode endpoints --skip-proximity --output <새 결과.json>
python cad/gesture_hand_v3/audit_fabrication.py --output <새 결과.json>
python cad/gesture_hand_v3/render_gestures.py --output <저장소 밖 새 폴더> --compare-reference
```

`baseline` 생성 단계는 원본 솔리드를 시각 형상에 맞게 변형한 비교용이며 제작용이 아니다. `roots`는 뿌리 모듈까지, `fabrication`은 이번 국부 제작 수정을 포함한다. 원본 native 입력127개 파일과 FORM002 입력은 해시로 확인한다. [입력 출처](source_native/README.md) · [수정 전 검사 기록](reviews/history/README.md)

커밋 후 정확한 SHA의 깨끗한 별도 사본에서 전체 형상·질량·관성을 재생성하고 보·바위·엄지척 및 공칭 체결을 재검사한다. 후속 기록의 대상 SHA와 범위는 저장소 `CHECKPOINT.json`을 따른다. 외부 독립 감사나 제조 출고 승인이 아니다.
