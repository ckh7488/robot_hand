# FORM002의 원본 솔리드 보존 사본

`cad/anatomy_candidate_v1`의 로컬 초안에서 FORM002 시각 메시를 만든 124부품 STEP, 장면 대응표, 치수와 원본 STL만 바이트 그대로 복사했다. 원래 초안은 형상 비율이 반려된 미커밋 자료이므로, 그 초안 전체를 현재 설계로 채택하거나 덮어쓰지 않는다. 이 사본은 수용한 FORM002의 실제 솔리드를 재구성하기 위한 출처다.

`manifest.json`은 원본과 사본이 동일함을 확인한 SHA-256이다. `build.py`는 이 솔리드에 명시적인 변환을 적용하고, 그 변환을 원본 STL의 모든 정점에 적용한 결과가 동결된 `accepted_form_v1` 메시와 0.001 mm 이내로 일치하는지 확인한다. 이 대응 검증으로 원본 STEP과 수용한 시각 형상의 관계를 연결한다.

출처의 관절 하드웨어와 구멍은 외형 변형 과정에서 변형됐으므로 비교용 baseline도 제작용으로 승인되지 않는다. 뿌리·핀·부싱·체결부의 제작 후보는 이 사본 밖의 `gesture_hand_v3` 생성 코드에서 별도로 수정한다. 여기의 원본 파일은 보존한다.
