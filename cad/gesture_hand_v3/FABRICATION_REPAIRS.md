# FORM002 외형의 국부 제작 구조 수정

`fabrication_repairs.py`는 수용된 외형의 native STEP 재구성본을 입력으로 받는다. `repair(parts, design) -> (parts, report)`이며, import 시 형상을 생성하거나 파일을 쓰지 않는다. 각 입력과 출력 부품은 전역 mm 좌표의 BRep, 명시적 관절 `body`, 재료와 밀도 가정을 가진다. 이전 후보와 수용된 시각 참고 자료는 수정하지 않는다.

## 수정 범위

- 원위 힌지 10개: 타원으로 변형된 표시용 핀·부싱을 실제 단면의 부품으로 교체한다. 외측 두 부싱과 중앙의 양쪽 플랜지 부싱은 D형 외측 키로 외피에 맞물린다. 핀은 머리, 왼쪽 회전방지 평면, 반대쪽 홈과 별도 클립을 가진다. 핀과 부싱의 끼워맞춤, 클립의 탄성 설치·수명은 아직 승인되지 않았다.
- 엄지 첫 원위 관절: 서로 다른 축소율 때문에 기존 두 타원 사이에 생긴 중립 간섭을, 최종 관절 프레임에서 반경 8.4 mm의 실제 중앙 눈구멍 여유로 다시 절삭한다. 이것만으로 전체 동작 여유를 통과로 판정하지 않는다.
- 엄지 최종 통로: 모든 보강·보스 결합 뒤 뿌리 R3.4 mm 통공을 마지막에 다시 절삭한다. 첫 원위 관절의 스러스트 와셔에는 R4.85 mm의 유한 포켓, 두 번째 원위 부싱 플랜지에는 R4.55 mm의 유한 포켓을 둔다. 기존 축과 좌면 위치는 유지한다. 보어 R3.4와 부싱 R3.38 사이의 반경 여유0.02 mm는 공칭 CAD 값이며 실제 프린트 정밀도나 끼워맞춤 승인값이 아니다.
- 덮개 체결 6개: 원형 포스트를 실제 손바닥 바닥에 합쳐 한 몸체로 만든다. 포스트 윗면과 와셔는 손바닥 덮개의 경사면에 맞춘다. 실제 축 길이를 가진 M3 볼트와 옆으로 삽입하는 너트를 추가하고, 원래 타원으로 변형된 덮개 구멍은 메운 뒤 원형으로 다시 가공한다.
- 접은 약지 아래의 덮개 체결 한 곳은 R4.3 mm·깊이0.5 mm 좌면 포켓에 와셔와 기존 높이의 나사 머리를 낮춰 둔다. 기존 식별자는 `-18_104`지만 실제 중심은 `[-5, 55×150/127]` mm다. 포스트·너트 좌면은 유지하며, 와셔 아랫면29.5 mm·윗면30.0 mm와 나사 축 길이를 함께 기록한다. 해당 덮개 수직 두께는3.5→3.0 mm이며 강도 승인을 뜻하지 않는다.
- 얇은 끝과 목: 원위 관절 부근의 지지되지 않는 얇은 립을 제거하고, 근위 목에는 바깥 바닥 기준을 유지한 안쪽 연결 웹을 추가한다. 웹의 지정 단면은 수직 방향 2.5–3.4 mm이며, 이는 전체 외피의 최소 두께나 강도 보증이 아니다.
- 장식판: 검은 판 9개와 흰 전이판 4개 중 새끼손가락의 길이 0.761 mm짜리 검은 조각은 별도 체결 공간이 없어 옆 흰 판과 합친다. 이 작은 색 경계는 사라진다. 남은 실제 판 12개에 보스·캡티브 M2 너트·두 개의 볼트와 좌면 와셔를 추가하고, 얇은 잘림 끝은 짧게 정리한다. 판은 공칭 0.9 mm 성형 금속 판재라는 새 재료 가정으로 구분하며, 기존 플라스틱과 동일 질량으로 취급하지 않는다.
- 손끝 캡 5개: 코어가 캡 앞벽을 침범하던 부분을 절삭한다. 코어 내부의 너트 보스는 지붕으로 이어지는 실제 리브로 연결하며, 캡 앞면의 매립된 M2 볼트 두 개가 이를 잡는다. 나사 머리는 원래 손끝 길이 안에 둔다.

`design.fabrication_extended_repairs=false`는 원위 힌지와 덮개만 따로 검증하기 위한 단계 선택이다. 기본값은 전체 수정이다.

## 검증 계약

수정되거나 추가된 부품은 출력 전에 유효한 연결 단일 솔리드인지 검사한다. 보고서에는 수정 전후 체적, 추가·제거 부품, 실제 핀 형상 간섭 검사 대상, 유한 축 구간, D키와 좌면, 볼트·너트 구간을 남긴다. D형 핀의 통로는 전체 원형 실린더 대신 실제 핀 형상으로 검사해야 한다.

전체 손의 저장된 STEP 재수입, 모든 같은 강체·다른 강체 부품의 중립 및 자세/전환 간섭, 체결 좌면과 삽입·공구 접근, 새 두께 표본은 별도 검사다. 공칭 나사 원통에는 실제 나선산이 없으며 나사 규격 구매 적합성, 체결 토크, 공차, 마찰, 피로, 구동 줄 경로와 실측 성능은 승인되지 않았다. 이 문서는 수정 의도와 검사 범위를 설명하며 제작 출고 승인서가 아니다.

## 단계별 단독 검사

동결된 수정 소스 `3747ec733ecb5e431d6ed5ea869770e8b3e22271b34dd74ba2fa9d03078bc587`와 수용된 native 입력으로 기본 단계와 확장 단계를 각각 실행했다. 확장 단계는 뿌리 모듈 교체 전의 원본 124개 부품을 입력으로 받아 281개 연결 단일 솔리드를 만들었다. 지정된 핀·부싱·덮개·장식·캡 관계 226쌍에서 물질 겹침이 없었다. 이 범위에는 기존 끝캡 5개의 약126 mm³ 겹침과 엄지 중앙 눈구멍의 7.05 mm³ 겹침 해소가 포함된다.

근위 목 14개에서 각각 네 위치에 둔 길이2 mm·반경0.15 mm의 실체 게이지 56개는 모두 재료 안에 들어갔다. 이는 지정 위치의 연결 웹 검사이며 표면 전체의 최소 두께 검사와 다르다. 통합 후 뿌리 교체·손바닥 결합으로 최종 부품 수는 달라지므로 최종 `build_report.json`을 따른다. 전체 손 자세, 저장 STEP 좌면, 모든 체결의 공구 접근은 이 단독 검사에 포함하지 않았다.

첫 확장 시도에서 새끼손가락의 얇은 검은 조각이 끝 정리 후 사라져 검사가 중단됐다. 이를 예외 처리하지 않고 인접 판에 통합한 뒤 재실행했다. 이 검사 이력은 해당 체크포인트의 검토 자료에 보존한다.

통합된349개 부품의 첫 전체 검사에서는 이 지정 관계 밖에 있던 엄지 간섭6쌍이 추가로 발견됐다. 뿌리 부싱 몸통과 외피 각37.491 mm³, 스러스트 와셔 각0.9158 mm³, 바깥 플랜지 각0.3762 mm³다. 뿌리 보어의 축과 일부 원통면은 정확했지만 유한 통로에 실제 재료가 남아 있었다. 저장 STEP8개를 다시 읽어 같은 R3.4 통공과 위 포켓을 시험했을 때 여섯 겹침은 모두0이었고 두 외피는 유효한 단일 솔리드였다. 이를 최종 절삭과 실제 하드웨어-외피 검사 항목에 반영했다. 이 작은 검사는 전체 자세·연속 전환의 통과 판정과 구분한다.
