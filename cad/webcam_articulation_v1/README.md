# 웹캠 관절 수정 후보

원본 `cad/form_candidate_v1`은 외형 기준으로 보존한다. 이 후보는 같은 손바닥 비율과 손가락 길이를 유지하며, 주먹과 엄지 굽힘을 실제 관절 형상에 반영한다. 구동 설계 중인 `cad/form_drive_v1`과 별개다.

## 변경

- 엄지 뿌리의 좌우 회전축과 굽힘축은 직각이다. 굽힘축을21mm 높여 손바닥 위에서 움직이는 지지대를 만들었다. 모터는 추가하지 않았다.
- 엄지 두 바깥 마디의 공통 기준축을 기존 방향에서65도 틀었다. `Rz(25°) @ Ry(-65°)`를 실제 포크 구멍·핀·부싱·메시·시뮬레이션에 같이 적용한다. 양의 굽힘은 손바닥 중심 쪽으로 감긴다.
- 뿌리 목을 좁히고 마디 접힘 쪽 외피를 덜어냈다. 손바닥 덮개에는 회전하는 뿌리 지지부의 여유 홈을 냈다. 각 출력 부품은 연결된 유효 솔리드1개다.
- 네 손가락의 주먹 목표는 뿌리80도, 가운데 약122~133도, 끝 약57~68도다. 해당 링크 길이에서 손끝과 손바닥 덮개 사이의 명목 여유가2mm다. 끝마디가 손바닥을 뚫게 해서 닫힘을 표현하지 않는다.
- 엄지의 주먹 목표는 좌우4.36도, 뿌리 굽힘41.77도, 두 바깥 마디34.46/51.76도다. 기준 경로는 엄지를 옆으로 벌려 들어 올림 → 네 손가락 접기 → 엄지 감기다. 모든 축의 단순 동시 보간은 일부 중간 자세에서 간섭하므로 기준 경로로 쓰지 않는다.

## 재현

CadQuery/OCP, NumPy, SciPy 환경에서 `build.py`로 STEP·STL120개·scene·design을 생성한다. 실행 시 BLAS/OpenMP 스레드 수1, D: 임시 폴더와 숨김 pythonw를 사용한다. `HAND_CAD_CACHE`로 절삭 캐시 경로를 지정할 수 있다. 캐시는 형상 제작 모듈 해시와 형상 측정값을 포함하며 Git에 저장하지 않는다.

`verify.py`는 STEP를 다시 읽고 부품별 체적과 경계로 scene 대응을 확인한다. 실제 엄지 포크의 원통 구멍축을 측정하고, 기준 경로13자세에서 주요 외피·손끝·뿌리 포크·손바닥 앞 덮개의 다른 강체 사이 교차 체적을 검사한다. 0.02mm³ 초과 교차가 있으면 실패한다. 주먹의 네 손끝 간격은1~3mm여야 한다. 결과는 `generated/motion_review.json`이다.

부싱·핀·나사·장식판 체결부, 같은 강체 내부 접합, 손바닥 뒤쪽과 모터는 이 간섭 검사에서 제외한다. 연속 경로 전체와 자유로운 관절 조합, 접촉 물리, 체결·강도·줄 경로·실물 구동은 검증하지 않았다. 13자세 통과를 전 영역 무간섭이나 제작 승인으로 해석하지 않는다.

## 확인 화면

`sim_3rd/hand_follow/model_check.py`: 카메라 없이 네 엄지 축과 주먹 자세를 확인한다.

`sim_3rd/hand_follow/render_model_review.py`: 동일 CAD의 편 손, 주먹 정면·사선·측면 및 관절 축 이미지를 만든다.

웹캠 앱의 새 기본 CAD이며, 이전 보정과 구별해 `calibration_articulation_v1.json`을 사용한다. 원본 CAD와 비교하려면 `--cad form_candidate_v1`을 지정한다.
